## 1. 畫面呈現

### 1.1 句子標題：句型＋完整公式

句型編號採**賴世雄（常春藤英文文法）的編號**（2026-09-27 由教法 B 改為此版），公式和片段標籤一致。

**句型編號一定要搭配完整公式一起出現**（例如「句型三：S + Vt + O」），任何地方都不能只寫「句型三」，因為不同教科書的編號不一樣。

| 句型 | 公式 | 動詞種類（賴世雄） | 例句 |
|---|---|---|---|
| 句型一 | S + Vi | 完全不及物動詞 | Birds fly. |
| 句型二 | S + V + SC | 不完全不及物動詞 | She is a nurse. |
| 句型三 | S + Vt + O | 完全及物動詞 | I like you. |
| 句型四 | S + Vt + O + OC | 不完全及物動詞 | The news made her sad. |
| 句型五 | S + Vt + IO + DO | 授予動詞 | The teacher showed us a picture. |

程式內部另有「內部代號」（1 S+Vi、2 S+Vt+O、3 S+V+SC、4 S+Vt+IO+DO、5 S+Vt+O+OC），只在程式和題庫資料裡使用，顯示時一律換成上表的編號（`backend/analyzer/schema.py` 的 `PATTERN_DISPLAY`）。

被動語態：標題寫「句型X（被動語態）：S + be + p.p. …」，X 是**改成被動之前**的句型（見 5.6）。

對等句：標題依序寫出每個子句的句型和公式，用「＆」連接，例如「句型三：S + Vt + O　＆　句型三：S + Vt + O」，旁邊加一個「對等句」小標籤；每個子句用外框圈起來，框上只寫「子句一」「子句二」（見 5.7）。

### 1.2 底線與圖例

| 呈現 | 意思 |
|---|---|
| 彩色實線底線 | 主幹，算進公式 |
| 彩色虛線底線 | 不算進公式（aux.、真主詞） |
| 括號 ( ) | 句子裡被省略的字，例如 (You) |
| 粗體＋下方小字「核心」 | 核心字（小字只在詳細模式顯示） |
| 灰色 | 修飾語 |

### 1.3 顏色

| 顏色 | 角色 |
|---|---|
| 藍 | S |
| 橘紅 | Vt、Vi、V、aux. |
| 綠 | O、IO、DO |
| 黃 | SC、OC |
| 灰 | 修飾語、引導詞 |
| 灰框白底 | 連接詞 conj. |

### 1.4 兩種模式

- **骨架模式**（預設）：只有主幹有顏色和標籤，修飾語變淡、不顯示標籤。
- **詳細模式**：修飾語顯示功能標籤，核心字下方顯示「核心」。

## 2. 主幹標籤

| 標籤 | 名稱 | 定義 | 例子 |
|---|---|---|---|
| `S` | 主詞 | 做動作的人事物，或被描述的對象 | **The teacher** showed us a picture. |
| `Vt` | 及物動詞 | 後面需要受詞 | She **reads** a book. |
| `Vi` | 不及物動詞 | 後面不需要受詞 | Birds **fly**. |
| `V` | 動詞（連綴） | 後面接主詞補語；「連綴動詞」只寫在說明裡，不出現在標籤上 | The soup **smells** good. |
| `aux.` | 助動詞 | 幫主要動詞表達時態、語氣、疑問、否定、被動；不算進公式 | She **has** finished. |
| `O` | 受詞 | 句型三、五的受詞 | I like **you**. |
| `IO` | 間接受詞 | 句型五：動作給「誰」 | He told **us** a story. |
| `DO` | 直接受詞 | 句型五：給「什麼」 | He told us **a story**. |
| `SC` | 主詞補語 | 說明主詞；主詞 ＝ 補語 | He became **a doctor**. |
| `OC` | 受詞補語 | 說明受詞；受詞 ＝ 補語 | We named our dog **Lucky**. |
| `conj.` | 連接詞 | 對等連接詞，連接兩個完整句子；不屬於任何子句、不算進公式 | I like tea, **but** she likes coffee. |
| `真主詞` | 真正的主詞 | 虛主詞 It 句型中被移到句尾的主詞；虛線，不算進公式 | It is hard **to learn English**. |
| `真受詞` | 真正的受詞 | 虛受詞 it 句型中被移到句尾的受詞；虛線，不算進公式（2026-09-29 新增，待確認） | I find it hard **to wake up early**. |

### 2.1 判斷方法（寫規則的依據）

| 要判斷的事 | 方法 |
|---|---|
| 主要動詞 | 句子的核心動詞；有時態變化、跟著主詞改變 |
| 主詞 | 問「誰／什麼」在做這個動作 |
| Vt 或 Vi | 動詞後面有沒有受詞 |
| SC | 等號測試：主詞 ＝ 補語 說得通 |
| IO＋DO | 改寫測試：能改成「DO ＋ to／for ＋ IO」 |
| O＋OC | 等號測試：受詞 ＝ 補語 說得通 |
| 修飾語 | 刪除測試：拿掉之後主幹仍然完整 |

## 3. 動詞的細部規則

| 情況 | 標法 | 例子 |
|---|---|---|
| 助動詞（be、have、do、can、will…） | 一律 `aux.`，主要動詞決定 Vt／Vi／V | She **is**(aux.) **reading**(Vt) a book. |
| 否定縮寫 | 整塊 `aux.` | **Don't**(aux.) run. |
| 進行式、完成式 | be／have 標 `aux.` | The baby **is**(aux.) **sleeping**(Vi). |
| be 動詞當主要動詞 | `V`（疑問句也一樣，不標 aux.） | **Is**(V) your sister a nurse? |
| There is／are 的 be | `Vi` | There **is**(Vi) a cat. |
| 被動語態 | be 標 `aux.`，p.p. 標 `Vt` | It **was**(aux.) **broken**(Vt). |
| 同一個動詞不同用法 | 看這一句的實際結構 | He **runs**(Vi) fast.／She **runs**(Vt) a shop. |

## 4. 修飾語

### 4.1 功能標籤

| 標籤 | 用在 | 例子 |
|---|---|---|
| `形容詞・修飾 X` | 修飾名詞，X 是被修飾的字 | the boy **with the big glasses**（修飾 boy） |
| `副詞・表時間` | 何時、多久 | **in the fall**、**every night** |
| `副詞・表地點` | 在哪裡、到哪裡 | **in the garden**、**home** |
| `副詞・表方式` | 怎麼做 | **happily**、**very fast** |
| `副詞・表目的` | 為了什麼 | **for Mom's birthday** |
| `副詞・表狀況` | 在什麼狀況下 | **Even in the heavy rain** |
| `副詞・表路程` | 多遠、經過哪裡 | **all the way to school** |
| `副詞・表語氣` | 禮貌、語氣 | **Please** |
| `副詞・表否定` | 否定（沒有跟在助動詞後面的 not、never） | it was **not** a piece of cake |
| `副詞・表執行者` | 被動語態的 by＋執行者 | **by the manager** |
| `副詞・表伴隨` | 跟誰一起（with ＋ 人） | **with his friends** |
| `副詞・表對象` | 動作或形容詞的對象（look at、interested in、popular with…） | looked **at the old photo**、excited **about the trip** |
| `副詞・分詞構句` | 沒有連接詞的分詞構句（見 5.12） | **Walking to school,** I saw a cat. |
| `同位語・說明 X` | 同位語，X 是被說明的名詞（見 5.11） | Paris, **the capital of France**, is… |
| `副詞子句・表時間／表原因／表條件／表讓步／表目的／表地點／表對比／表結果` | 從屬連接詞帶頭的副詞子句（見 5.8） | **Because it was raining,** we stayed home. |
| `引導詞` | There is 句型的 There | **There** is a cat. |

- 新增功能標籤前要先確認，並更新這張表。
- **副詞不標修飾對象**，只標功能（例如 *in the garden* 標「副詞・表地點」）。
- **形容詞一定標修飾對象**；對象可以在另一個修飾語裡，例如 *the leaves on the big trees **near the river*** 的 near the river 修飾 trees。
- 修飾語的「結構」（介系詞片語、名詞片語…）**不顯示在畫面上**，寫在點開的說明裡。

### 4.2 模稜兩可時怎麼辦

介系詞片語到底修飾名詞還是修飾動詞，**要看情況**，不設一律的預設值。做法：

1. **依照分析程式的判斷**：分析程式從大量真實句子學過「這個片語通常掛在哪裡」，它把片語掛在名詞上 → 標「形容詞・修飾 X」；掛在動詞上 → 標「副詞・表…」。
2. **兩種理解都說得通時，在說明裡補一句**：例如「也可以理解成『花園裡的小花』，意思差不多」。
   - 程式判斷「兩種都說得通」的條件：片語緊接在受詞後面，而且是表地點、時間的介系詞（in、on、at、near…）。
3. **使用者回報這類錯誤時**，加進題庫，逐步修正。

## 5. 片段切分與特殊句型

### 5.1 切分原則

- **以片語為單位**：冠詞、形容詞、所有格跟名詞放在同一塊（*my little brother*）。
- **名詞後面的修飾片語另外切一塊**（*the boy* ／ *with the red cap*）。
- **對等連接放在同一塊**：*rice, corn, and many kinds of fruit*、*red and yellow*。
- **不定詞、動名詞當受詞時整塊**：*to go home*、*playing basketball*。
- **名詞子句當受詞時整塊**：*that he is right*。
- **形容詞子句整塊當修飾語**：*who likes to cook*（第 1 階段不展開，第 2 階段可以點開）。
- **助動詞和主要動詞分開**，中間可以夾副詞：*has*(aux.) ／ *already*(副詞) ／ *finished*(Vt)。

### 5.2 核心字

**定義**：片語中其他字都在形容它的那個字；拿掉其他字，句子仍然講得通。

| 情況 | 核心字 | 例子 |
|---|---|---|
| 一般名詞片語 | 名詞本身 | *The old **tree*** |
| 對等連接 | 每一個都標 | ***rice**, **corn**, and many **kinds** of fruit* |
| 數量詞＋of＋名詞 | **不標**，附文法重點卡 | *Most of the kids*、*each of us* |
| 單位詞＋of＋名詞 | of 後面的名詞 | *a glass of **water*** |
| 只有一個字的片段 | 不標 | *us*、*Everyone* |
| 形容詞片語 | 形容詞本身 | *very **fun*** |

### 5.3 There is／There are

- 歸為句型一：`[引導詞 There] [Vi is] [S a cat]`
- 附「There is／There are 句型」文法重點卡。

### 5.4 祈使句

- 省略的主詞顯示為 `(You)`，標 `S`，實線底線，放在主要動詞（或否定 aux.）前面。
  - *Please (You) keep the door open.*、*(You) Don't run in the hallway.*
- 附「祈使句」文法重點卡。
- **Let's**（使用者決定，2026-09-29）：Let's 是提議「我們一起…吧」的祈使句。`Let` 標 `aux.`（不算進公式），`'s`（＝us）標 `S`，句型看後面的動詞：
  - `[aux. Let] [S 's] [Vi go] [M 副詞・表地點 to the park]` → 句型一：S + Vi；畫面上 's 顯示成 's（us），說明寫「Let's＝Let us，不是 Let is」（使用者要求）
  - *Let's not argue.* → `[aux. Let] [S 's] [aux. not] [Vi argue]`
  - 只有縮寫的 Let's 這樣標。*Let me help you.*、*Let us know.* 是使役動詞：`[S (You)] [Vt let] [O me] [OC help you]` → 句型四：S + Vt + O + OC。

### 5.5 疑問句

- 助動詞移到句首：`[aux. Can] [S you] [Vt pass] …`
- be 動詞當主要動詞時標 `V`：`[V Is] [S your sister] [SC a nurse]`
- 附「助動詞疑問句」文法重點卡（be 動詞疑問句的卡片之後再加）。

### 5.6 被動語態

- 標題：「句型X（被動語態）」，X 是主動句的句型（只有句型三、四、五能改被動）。
- `be` 標 `aux.`，`p.p.` 標 `Vt`，`by＋執行者` 標 `副詞・表執行者`。
- **被動後剩下的部分照原本的角色標**：
  - *Tom was given **a bag**.* → a bag 標 `DO`（句型五）
  - *He was elected **class leader**.* → class leader 標 `OC`（句型四）
- 附「被動語態」文法重點卡。

### 5.7 對等句（對等連接詞 and、but、or、so…）

- 兩個完整句子各自拆解，每個子句用外框圈起來，框上寫「子句一」「子句二」。
- 連接詞標 `conj.`，放在兩個子句中間，不屬於任何子句。
- 標題：「句型X：公式　＆　句型Y：公式」，旁邊加「對等句」小標籤。
- 附「對等連接詞」文法重點卡（FANBOYS、逗號、拆開測試）。
- 只連接兩個字或片語（*tea and coffee*、*red and yellow*）不算對等句，照 5.1 放在同一塊。

### 5.8 副詞子句（從屬連接詞 because、when、if、although…）

- 標題顯示**主要句子**的句型。
- 副詞子句整塊當修飾語，標 `副詞子句・表原因／表時間／表條件／表讓步／表目的`；點開可以看子句內部的拆解（連接詞標 `conj.`）。第 1 階段先整塊顯示，展開功能在第 2 階段。
- 從屬連接詞的分類：

  | 功能 | 從屬連接詞 |
  |---|---|
  | 表時間 | when、while、before、after、until、since、as soon as |
  | 表原因 | because、since、as |
  | 表條件 | if、unless |
  | 表讓步 | although、though、even though |
  | 表目的 | so that |

- 附「從屬連接詞與副詞子句」文法重點卡（逗號規則、✗ Because…so、✗ Although…but）。
- 多字連接詞也要認得（Azar 17-1）：as soon as、by the time、every time、as long as、in case、only if、even if、even though、now that、so that。
- since：主要句子是完成式時表時間（Since I came here, I have learned…），否則表原因。
- whereas 表對比；while 預設表時間。
- 注意：before、after、since 也可以當介系詞（*before school*），後面接的是名詞時照一般修飾語處理。

### 5.8.1 so／such … that（Azar 19-4）

- that 子句標 `副詞子句・表結果`，可以點開。
- 涵蓋 so ＋ 形容詞（so excited that…）、so ＋ 副詞（speaks so fast that…）、such ＋ 名詞（such good coffee that…）。
- 附「so／such … that」文法重點卡。

### 5.8.2 平行結構（Azar 16-1）

- 一個主詞後面接兩個以上的動詞（*read books **and practice** writing*），是**一個句子**，不是對等句，不畫子句框。
- 連接詞標 `conj.`。
- 標題：句型相同時寫「句型三：S + Vt + O（兩組 Vt + O 並列）」；句型不同時各自列出，後面的主詞加括號：「句型一：S + Vi　＆　句型三：（S）+ Vt + O」。
- 附「平行結構」文法重點卡。

### 5.9 動名詞、不定詞當主詞

- `[S Swimming] [V is] [SC fun]` → 句型二。
- 附「動名詞當主詞」文法重點卡（視為單數）。

### 5.10 虛主詞 It

- `[S It] [V is] [SC hard] [真主詞 to learn English]` → 句型二：S + V + SC。
- It 標 `S`（說明裡註明是虛主詞）；真主詞用虛線，不算進公式。
- 附「虛主詞 It」文法重點卡（還原測試、常見誤判為 S + V + O）。
- 與 There is 的差別：There is 的 There 標「引導詞」，真正的主詞標 `S`；It 句型的 It 標 `S`，真正的主詞標「真主詞」。兩者都是常見教法。
- **for ＋ 人 ＋ to V**（使用者決定，2026-09-29）：*It is hard **for me to learn English**.* → for me to learn English 整塊標 `真主詞`，說明寫「for ＋ 人 說明誰去做」。句型二：S + V + SC。
- **of ＋ 人**：*It is kind **of you** to help me.* → of you 標 `副詞・表對象`（跟著形容詞 kind，說的是人的個性），to help me 標 `真主詞`。for／of 的分辨寫在虛主詞卡：形容詞說「事情」用 for，說「人的個性」用 of。

### 5.10.2 強調句 It is … that …（使用者決定，2026-09-29）

- 照「還原句」判斷句型：*It was John who broke the window.* → *John broke the window.* → 句型三：S + Vt + O。
- `It was`、`who／that` 標 `強調框架`（EF，不算進公式，樣式同連接詞）。
- 被強調的部分標它在還原句裡的角色，說明寫「被強調的部分」：
  - `[強調框架 It was] [S John] [強調框架 who] [Vt broke] [O the window]` → 句型三
  - `[強調框架 It was] [M 副詞・表地點 in the park] [強調框架 that] [S I] [Vt met] [O her]` → 句型三
  - *It was yesterday that…*：時間名詞標 `副詞・表時間`；*It was not until midnight that…*：not 標 `副詞・表否定`。
- 只認有把握的強調句（見 `engine.py` 的 `cleft_clause`）；形容詞後面接 that 子句（*It is true that…*）仍是虛主詞句。
- 附「強調句」文法重點卡。

### 5.10.1 虛受詞 it（2026-09-29 夜間新增，待使用者確認）

- `[S I] [Vt find] [O it] [OC hard] [真受詞 to wake up early]` → 句型四：S + Vt + O + OC。
- it 標 `O`（說明裡註明是虛受詞）；形容詞或名詞標 `OC`；句尾的 to V／that 子句標 `真受詞`（虛線，不算進公式）。
- 常見動詞：find、make、think、consider、believe；*make it a rule to…*、*make it clear that…*、*take it for granted that…*（for granted 標 OC）。
- 依據：台灣教學網站、常春藤、語言學（受詞外置）說法一致，見〈文法研究-七個進階句型.md〉第 2 節。

### 5.11 同位語（Azar 13-15）

- 標 `同位語・說明 X`：*Paris, **the capital of France**, is…*、*My friend **Tom** lives…*

### 5.12 分詞構句（Azar 第 18 章）

- 有連接詞的（*While walking…*、*After finishing…*）：依連接詞標 `副詞・表時間` 等（是副詞片語，不是副詞子句，因為沒有主詞）。
- 沒有連接詞的（*Walking to school,*）：標 `副詞・分詞構句`，說明它常表示「同時」或「原因」。
- 附「分詞構句」文法重點卡。

### 5.13 形容詞後面的介系詞片語（使用者決定，2026-09-27）

- 另外切成一塊，不併進補語：*so excited* ／ ***about the school trip***、*popular* ／ ***with tourists***。
- 功能：固定搭配（interested in、good at、famous for…）標 `副詞・表對象`；時間、場所才標表時間、表地點。
- 狀態被動（*is interested in*、*is made of*）同樣處理。

### 5.14 名詞後面的形容詞片語（Azar 13-15）

- *the woman **responsible for the error*** → `形容詞・修飾 woman`。

### 5.15 狀態被動（Azar 11-5）

- 沒有 by 片語、描述現有狀態的過去分詞當形容詞用：*is crowded*、*is interested in*、*is made of* → 句型二 S + V + SC。
- 判斷依據：常見的形容詞性過去分詞清單，或「分詞 ＋ 固定介系詞」清單（lexicon.py 的 ADJ_PARTICIPLES、STATIVE_PAIRS）。

### 5.16 必需的地點（參考七大句型的 SVA、SVOA）

- 網站仍以五大句型為主，地點照樣標 `副詞・表地點`。
- 但 be、live、put、place、lay、set、stay 後面的地點，說明欄會提醒「這個地點是動詞必需的，拿掉之後句子就不完整」。
- **be ＋ 地點**（*I am at school.*）：使用者決定（2026-09-27）採傳統五大句型最常見的分類 → 句型一 S + Vi。am 表示「在」，標 Vi；*at school* 標 `副詞・表地點`。有些文法書（賴世雄）把地點當主詞補語（句型二），介紹頁的「看更多」會提到。

### 5.17 照賴世雄標法的補語（使用者決定，2026-09-27）

- **seem／appear ＋ 不定詞**：不定詞是主詞補語 → 句型二 S + V + SC（賴世雄 p.32）。
  - *He seems **to know the answer**.*、*She seems **to be a kind person**.*
  - 其他動詞 ＋ 不定詞照舊當受詞：*He wants **to go home**.* → 句型三 S + Vt + O。
- **動詞 ＋ 受詞 ＋ into／as 片語**：片語是受詞補語 → 句型四 S + Vt + O + OC（賴世雄 p.54、p.58）。
  - *turned him **into a good student***、*regard him **as a genius***、*see Taipei 101 **as a symbol of Taiwan***
  - 被動句照 5.6，留下的片語維持受詞補語：*He is regarded **as a great leader**.* → 句型四（被動語態）。
  - 適用的動詞見 lexicon.py 的 OC_PREP_VERBS（turn／change／make … into；regard／view／see／treat／describe … as 等）。
  - 暫不處理：*take him for a fool*（和 *take the dog for a walk* 容易混淆）、*think of him as*（受詞在介系詞片語裡）。
  - 沒有受詞時照舊是修飾語：*She works **as a nurse**.* → 句型一 S + Vi。
- **沒有受詞的補語一律是主詞補語**：*He seems **happy**.*、*The door swung **open**.* → 句型二 S + V + SC。

### 5.18 名詞子句與附加問句（動詞字典試跑後修正，2026-09-27）

- **省略 that 的名詞子句、疑問詞開頭的名詞子句**：整個子句是受詞，不是「受詞＋受詞補語」。
  - *She said **she was tired**.*、*I know **where you will go**.* → 句型三 S + Vt + O
  - 判斷：子句裡有助動詞（was、will、didn't…）就是完整子句；沒有助動詞的才可能是小子句（*made **us** **clean** the room*）。
- **附加問句**：句尾的 *did she?*、*isn't it?* 標 `附加問句`，不算進公式，句型看前面的主要句子。
  - *She didn't do it, **did she**?* → 句型三 S + Vt + O
- **suggest／demand／insist／recommend ＋ 子句（子句裡用原形動詞）**：整個子句是受詞。
  - *I suggest **you do that**.* → 句型三 S + Vt + O

### 5.19 助動詞、不定詞、省略句（2026-09-27）

- **have to／has to／had to**：當助動詞（`aux`，顯示成一塊「has to」），後面的動詞才是主要動詞。
  - *I **have to** finish my homework.* → 句型三 S + Vt + O；*It **has to** be done.* → 句型三（被動語態）
  - *I have a lot of homework to do.* 的 have 是「有」，照舊是主要動詞。
- **動詞 ＋ 受詞 ＋ 不定詞**：
  - 動詞在 lexicon.py 的 VERB_OBJ_TO_V（ask、want、tell、allow、expect…，以及 consider、believe 這類「認為」動詞）→ 不定詞是受詞補語，句型四 S + Vt + O + OC。*I want **you** **to come**.*
  - 其他動詞 → 不定詞是 `副詞・表目的`。*I used the cupboard **to store food**.* → 句型三 S + Vt + O
  - 例外：*to be …* 一律是受詞補語；主詞是 It 的交給虛主詞規則（5.10）。
- **It takes／costs ＋ 人 ＋ 時間／金錢 ＋ to V**：人是 IO，時間／金錢是 DO，to V 是真主詞 → 句型五 S + Vt + IO + DO。
  - *It takes **me** **an hour** **to get to school**.*
- **放在動詞後面、當副詞用的形容詞**（lexicon.py 的 ADVERBIAL_ADJS，目前只有 alone）：標 `副詞・表方式`；連綴動詞後面照舊是補語。
  - *He lives **alone**.* → 句型一 S + Vi；*She felt **alone**.* → 句型二 S + V + SC
- **省略句**：只有助動詞、後面的動詞省略了，標題寫「省略句：S + 助動詞（後面的動詞省略了）」，不套句型。
  - *I can't.*、*Yes, I will.*；對等句裡的另一半照常分析：*I can't, and I don't want to.*
- **縮寫 'll**：名詞後面的 'll 也拆開當助動詞（*this rain**'ll** last*）。

### 5.19 體檢後補的規則（2026-09-29，Claude 照建議先做，待使用者確認）

- **片語動詞當 Vt**：片語清單（`analyzer/phrases.yaml`）上的介系詞動詞，後面接名詞時「動詞＋介系詞」整組是 Vt，名詞是 O → 句型三。
  - *She **looks after** her brother.*、*We **ran out of** milk.*、*I am **looking forward to** the trip.*、*I **ran into** an old friend.*
  - 動詞本身已經有受詞時不套用：*turned **him** into a good student* 照 5.17 是受詞補語。
  - 被動句介系詞後面沒有名詞時，介系詞一樣併進動詞：*The baby was **looked after** by her aunt.*
  - 不在清單上的（*look at the photo*、*listen to music*）維持 `副詞・表對象`（見待審核清單）。
  - 片語動詞整組當 Vt 時，不做「動詞句型字典」檢查（*depend on you* 的 depend 在字典裡是 Vi，原本會誤跳「⚠️ 這句可能分析錯了」）。
- **be going to**：*are going to* 整組是 aux.，後面的原形動詞才是主要動詞。*I'm going to school*（去學校）不受影響。
- **be ＋ 子句／不定詞 = 主詞補語**：*The problem **is** [that we have no money].*、*My dream **is** [to become a doctor].* → 句型二。主詞是 It 時仍照虛主詞規則。
- **只有 not、n't 併進助動詞**：*has **never** been* 的 never 標 `副詞・表否定`。
- **疑問詞的功能**：Where → `副詞・表地點`、When → `副詞・表時間`、Why → `副詞・表原因`（新增）、How → `副詞・表方式`。
- **比較**：*taller **than her sister*** 的 than 片語標 `副詞・表比較`（新增）。
- **句首的形容詞片語**：***Tired after work**, he went to bed.* 標 `副詞・分詞構句`（省略了 Being）。
- **used to／had better／would rather**：整組是 aux.（*I **used to** play…*、*You **had better** see…*、*I **would rather** stay…*）。*be used to* ＋ V-ing（習慣於）不受影響。
- **in order to／so as to ＋ 原形動詞**：整組 `副詞・表目的`；沒有主詞的不定詞片語是「副詞」不是「副詞子句」。
- **as if／as though**：`副詞子句・表方式`；**No matter what…**：`副詞子句・表讓步`。
- **介系詞功能補充**：of 片語預設 `副詞・表對象`（*reminded me **of my mother***）；*prefer A **to B*** 標 `副詞・表比較`；*thank／apologize … **for*** 標 `副詞・表原因`；with ＋ 名詞 ＋ 分詞／形容詞（附帶狀況，*with his eyes closed*）標 `副詞・表狀況`。
- **同位語子句**：fact、news、idea、belief 等名詞後面接 that ＋ 完整句子，that 在子句裡不當主詞或受詞 → `同位語・說明 X`（*The fact **that he lied***）；that 當受詞的仍是形容詞子句（*The news **that he told me***）。
- **自動抓錯**：同一個子句出現兩個主詞、受詞或補語（平行結構除外），一定有地方分析錯了 → 狀態改成「部分分析」並提醒使用者。
- **be supposed to／be able to**：整組是 aux.（*You **are supposed to** finish it.*、*She **was able to** swim…*）。
- **So do I.／Neither can she.**：省略句；So 標 `副詞・表語氣`、Neither 標 `副詞・表否定`。
- **hardly／scarcely／barely**：`副詞・表否定`。**instead of** 標 `副詞・表方式`、**because of** 標 `副詞・表原因`、**in spite of** 標 `副詞・表讓步`。
- **子句片段裡的修飾語不拆出來**：*found [that people who sleep less… are more likely…]* 整段是受詞，裡面的形容詞子句在展開子句時才看得到。
- **強調句**：先前暫標部分分析；2026-09-29 使用者決定照還原句標，見 5.10.2。
- **動名詞當真主詞**（2026-09-29 夜間，修錯）：*It is no use crying over spilt milk.*、*It is fun playing with you.* → V-ing 片語標 `真主詞`（原本被標成 O，句型二裡出現受詞）。
- **自動抓錯補充**：同一個子句裡同時有連綴動詞 V 和受詞 O，一定是看錯了 → 標部分分析。
- **第五批體檢修錯**（2026-09-29 夜間）：①倒裝句（*Never have I…*、*Only then did I…*、*So helpful is Bill that…*）沒有問號、句首也不是助動詞時，不附「是非疑問句」卡；②*as tall **as her brother*** 的第二個 as 片語標 `副詞・表比較`（跟 than 片語一樣）；③句首的 *Little did he know…* 的 Little 標 `副詞・表否定`；④*The number of students is…* 看 number（單數），不附「數量詞＋of」卡；⑤受詞是子句（*realize [my phone was missing]*）時不附「不定詞、動名詞當受詞」卡。
- **第六批體檢修錯**（2026-09-29 夜間）：①*My brother enjoys playing…* 分析程式把 enjoys 看成助動詞時，主語原本被併進動詞，已修正；②*There used to be a tree here.* There 標 `引導詞`、used to 標 aux.、be 標 Vi、a tree 標 S（句型一，跟 There is 一樣）；③*either … or* 的 either 標 conj.；④被動或授與動詞後面的 *to him*、*to her mother* 標 `副詞・表對象`（原本表地點）；⑤*How long*、*How often* 標 `副詞・表時間`，*How far* 標 `副詞・表路程`；⑥*In my opinion* 標 `副詞・表語氣`；⑦*a lot of homework **to do*** 修飾 homework，不是 lot。
- **第七批體檢修錯**（2026-09-29 夜間）：①*makes you **happier*** 比較級當受詞補語（原本 you happier 併成一塊受詞）；②「數量詞＋of」卡只在主詞時出現（*is one of the biggest problems* 是補語，不附）。
- **省略 if 的假設語氣**（2026-09-29 夜間）：*Had I known…*、*Were I you…*、*Should you need help…*（had／were／should 移到主詞前）→ 整塊 `副詞子句・表條件`，跟 if 子句一樣。
- **would／should／must have ＋ p.p. 不是現在完成式**：不附「現在完成式」卡（修錯）。
- **the ＋ 比較級, the ＋ 比較級**（2026-09-29 夜間，待使用者確認）：前半 *The more you practice* 整塊 `副詞子句・表條件`；後半照還原句標：*the better you get* → *you get better*，the better 標 `SC`（句型二：S + V + SC）；*the more money you will earn* → the more money 標 `O`（句型三：S + Vt + O）；*the sooner* 這類副詞照一般副詞標。沒有動詞的 *The sooner, the better.* 還不能分析。

## 6. 「未分析」規則

以下情況，相關片段標灰色「未分析」，畫面上方顯示「這句比較複雜，部分內容尚未分析」：

1. 找不到主要動詞，或找到不只一個（而且不是對等連接）
2. 轉換規則互相矛盾（例如同一個片段同時符合 IO 和 OC）
3. 分析程式的結果和字表衝突，而且無法判斷誰對
4. 屬於下方「尚未涵蓋」清單的句型

**原則：寧可標「未分析」，也不給一個可能錯的答案。**
