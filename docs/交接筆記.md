> 最後更新：2026-09-27。對話很長、可能被壓縮時，先讀這份，再讀〈標籤規則.md〉〈待審核清單.md〉〈整體路線圖與未來功能.md〉。

## 專案一句話

台灣英文學習者用的「英文句子骨架分析」網站：輸入英文句子或文章 → 標出 S／V／O／C、修飾語、句型（賴世雄版編號＋公式）、文法重點卡、翻譯、朗讀。全部免費、在自己的伺服器上執行（不呼叫 Claude API，不耗 token）。

## 怎麼啟動

```bash
cd ~/Desktop/english && .venv/bin/uvicorn backend.app:app --port 8765
```

打開 http://127.0.0.1:8765 。內建瀏覽器的自動啟動沒有權限讀桌面資料夾，所以要從終端機啟動。

## 重要的設計決定（細節見 docs/標籤規則.md v1.4）

- 分析：spaCy 大型模型（en_core_web_trf）找依附關係 → `backend/analyzer/engine.py` 的規則轉成課本標籤；字表在 `lexicon.py`、說明範本在 `notes.py`、資料格式在 `schema.py`。
- 句型編號：**賴世雄（常春藤）版**：句型一 S+Vi、二 S+V+SC、三 S+Vt+O、四 S+Vt+O+OC、五 S+Vt+IO+DO。程式內部代號不同（1 SV、2 SVO、3 SVC、4 SVOO、5 SVOC），顯示時用 `PATTERN_DISPLAY` 轉換。**句型編號一定要搭配公式出現。**
- 動詞標籤只用 Vt／Vi／V（不用 LV）；助動詞 aux.；被動語態照原本角色標；平行結構不畫子句框；同位語標「同位語・說明 X」；分詞構句；形容詞後面的介系詞片語另外切開（表對象）。
- 朗讀：Kokoro-82M（`backend/tts.py`），聲音只暫存記憶體、不寫檔（隱私）。
- 翻譯：伺服器上的 Qwen3-4B（`backend/translate.py`，llama-cpp-python，只用 CPU），OpenCC 轉台灣繁體、「菸」用字修正、夾英文時重翻、記憶體暫存、每分鐘 60 句上限；`/api/translate` 失敗時前端改用 Chrome 內建翻譯。模型檔 `models/Qwen3-4B-Instruct-2507-Q4_K_M.gguf`（`bash spikes/download_models.sh` 下載）。
- 片語：`backend/analyzer/phrases.yaml`（約 300 個）＋ `phrases.py`（依附關係或連續字比對）→ SentenceResult.phrases → 句子下方「片語」卡；慣用語的意思會當提示送給翻譯模型。YAML 裡的 on／off 要加引號（不然會變 true／false，程式會報錯提醒）。測試：`.venv/bin/python tests/phrases_test.py`（不要拿考試題調整片語）。
- 畫面（2026-09-27 使用者要求）：沒有圖例、沒有朗讀速度按鈕；分享、列印在結果下方的「看完了嗎？」框；卡片圖示 公式 📍、常見錯誤 ⚠️。
- 使用者偏好：白話、結論先講、全形標點；只挑不確定的地方請他確認；他不在時照建議做並記在 docs/待審核清單.md。
- 同一個資料夾可能同時有另一個對話在做「動詞句型字典」（verb_patterns.yaml、tools/build_verb_dict.py），存 git 時只加自己改的檔案。

## 已完成：翻譯模型實測（2026-09-27）

- 候選：OPUS-MT＋OpenCC、Qwen3-4B-Instruct-2507（GGUF Q4_K_M）、Breeze-7B-Instruct（GGUF Q4_K_M，YC-Chen 版）。三個都是 Apache 2.0。
- 下載：`spikes/download_models.sh`（可續傳；GGUF 存在 `models/`，OPUS 在 Hugging Face 快取）。使用者網路只有約 0.5～1 MB/s，全部下載約 4 小時。
- 實測：`HF_HUB_OFFLINE=1 .venv/bin/python -u spikes/translate_eval.py <模型名稱>`，結果累積在 `spikes/translate_results.json`，並產生 `docs/翻譯實測-原始結果.md`。
- 測試句 26 句：使用者回報（Voting、give someone a big hand）、慣用語、台灣用語、題庫句子。
- Qwen、Breeze 需要 llama-cpp-python（安裝時要在本機編譯）。**這台 Mac 的 Command Line Tools 有殘缺**：`/Library/Developer/CommandLineTools/usr/include/c++/v1` 只剩 3 個檔案，C++ 程式會找不到 `<mutex>` 等標頭檔。繞過方法（不動系統）：
  `CXXFLAGS="-isystem /Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/c++/v1" CMAKE_ARGS="-DGGML_METAL=on" .venv/bin/pip install llama-cpp-python`
- **已完成**（2026-09-27）：三個都測完，見 `docs/翻譯實測-比較報告.md`。結果：Qwen3-4B 22／26 正確（建議採用）、Breeze-7B 20、OPUS-MT 16。建議另做「慣用語清單＋文法重點卡」。使用者同意採用 Qwen3-4B，Breeze／OPUS 模型檔已刪除。
