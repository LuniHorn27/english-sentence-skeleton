# 五大句型教學影片：分鏡腳本

> 給英文初學者（國小、國中生）的教學影片，看完就懂「什麼是五大句型」。
> 橫式 1920×1080、約 4～5 分鐘；**中文旁白＋一模一樣的字幕**，英文例句用 Kokoro 語音（和網站朗讀同一個聲音）。
> 程式在 `video/`：旁白和字幕在 `video/src/narration.json`，畫面安排在 `video/src/scenes.ts`。**改旁白時，這份文件和 narration.json 要一起改。**

## 共同規則

- 句型編號採賴世雄版，**一律和公式一起出現**（例如「句型三：S + Vt + O」）。
- 積木顏色和網站一樣：S 藍、V 橘、O 綠、C 黃；修飾語灰色。
- 每個積木上方有小標籤（S、Vi、SC…），和網站分析頁的標法一致。
- 所有例句都用網站的分析程式跑過，結果和影片一致（2026-09-28 確認）。
- 例句和旁白全部自己寫，不用文法書或其他影片的內容。

## 寫旁白的原則（國小、國中生看得懂）

- 一句只講一件事，一行最多約 20 個字。
- 用說話的口氣：「是不是」「試試看」「呢」。
- 文法名詞第一次出現時，馬上用白話解釋：受詞＝動作的對象；補語＝補充說明前面的人或東西。
- 同一種判斷用同一句話：每個句型都問「它是受詞，還是補語呢？」「用等號試試看」，讓學生養成習慣。
- 旁白唸「＝」時說「等於」、唸公式時說「S 加 V T 加 O」；字幕照原樣顯示符號。
- 每一拍的長度自動配合旁白：旁白唸完才換下一個畫面。

## 逐段腳本

「🔊」＝唸英文例句（這時候沒有中文旁白）。「（只唸）」＝標題已經在畫面上，不再顯示字幕。

### 段落 1　認識積木

| 畫面 | 旁白／字幕 |
|---|---|
| 四個空位 | 英文句子，就像拼積木。 |
| S 積木出現 | 藍色的 S 是主詞：這句話在說誰。 |
| V 積木出現 | 橘色的 V 是動詞：主詞做了什麼。 |
| O 積木出現 | 綠色的 O 是受詞：動作的對象。 |
| 我喜歡音樂：「音樂」亮起來 | 像「我喜歡音樂」，音樂就是受詞。 |
| C 積木出現 | 黃色的 C 是補語：補充說明前面的人或東西。 |
| 灰色積木出現 | 灰色的是修飾語：說明時間、地點、方法。 |
| 灰色積木拿掉 | 修飾語拿掉，骨架還在。 |
| V 積木亮起來 | 重點來了：先找到動詞， |
| V 後面出現「？」 | 再數一數，動詞後面接了幾塊積木。 |

### 段落 2　句型一：S + Vi

| 畫面 | 旁白／字幕 |
|---|---|
| 大標題，縮到左上角 | 句型一：S + Vi（只唸） |
| Birds、fly 掉下來 🔊，中譯「鳥會飛。」 | — |
| 下方出現「動詞後面：0 塊」 | 動詞後面，什麼都不用接。 |
| — | 鳥會飛，意思已經很完整了。 |
| 灰色 in the sky 接到後面 🔊 | 加上 in the sky，在天空， |
| in the sky 縮小消失 | 這是修飾語，拿掉也沒關係。 |
| fly 的標籤 Vi 閃一下 | Vi 叫做不及物動詞：後面不用接受詞。 |

### 段落 3　句型二：S + V + SC

| 畫面 | 旁白／字幕 |
|---|---|
| 大標題，縮到左上角 | 句型二：S + V + SC（只唸） |
| She、is、a nurse 掉下來 🔊，中譯「她是護理師。」 | — |
| a nurse 出現數字 1 | 這次，動詞後面接了一塊。 |
| — | 它是受詞，還是補語呢？ |
| 下方出現 She ＝ a nurse ？ | 用等號試試看：她＝護理師。 |
| 變成 ＝ ✓ 說得通 → 補語；SC 閃一下 | 說得通！所以它是補語 SC。 |
| — | 補語用來說明主詞是什麼。 |

### 段落 4　句型三：S + Vt + O

| 畫面 | 旁白／字幕 |
|---|---|
| 大標題，縮到左上角 | 句型三：S + Vt + O（只唸） |
| I、like、music 掉下來 🔊，中譯「我喜歡音樂。」 | — |
| music 出現數字 1，下方「動詞後面：1 塊」 | 動詞後面，也接了一塊。 |
| — | 它是受詞，還是補語呢？ |
| 下方出現 I ＝ music ？ | 用等號試試看：我＝音樂？ |
| 變成 ≠ ✗ 說不通 → 受詞 | 我不是音樂，說不通！ |
| O 閃一下 | 說不通，所以它是受詞 O，就是動作的對象。 |
| Vt 閃一下 | Vt 叫做及物動詞：後面一定要接受詞。 |

### 段落 5　句型四：S + Vt + O + OC

| 畫面 | 旁白／字幕 |
|---|---|
| 大標題，縮到左上角 | 句型四：S + Vt + O + OC（只唸） |
| The news、made、her、sad 掉下來 🔊，中譯「這個消息讓她很難過。」 | — |
| her、sad 出現數字 1、2 | 這次，動詞後面接了兩塊。 |
| her 閃一下 | her 是受詞。那 sad 呢？ |
| 下方出現 her ＝ sad ？ | 用等號試試看：她＝難過。 |
| 變成 ＝ ✓ | 說得通！她很難過。 |
| OC 閃一下 | 所以 sad 是受詞補語 OC，用來說明受詞。 |

### 段落 6　句型五：S + Vt + IO + DO

| 畫面 | 旁白／字幕 |
|---|---|
| 大標題，縮到左上角 | 句型五：S + Vt + IO + DO（只唸） |
| He、gave、me、a book 掉下來 🔊，中譯「他給我一本書。」 | — |
| me、a book 出現數字 1、2 | 動詞後面也接了兩塊：先接人，再接東西。 |
| 下方出現 me ＝ a book ？ | 用等號試試看：我＝一本書？ |
| 變成 ≠ ✗ | 說不通！所以兩塊都是受詞。 |
| IO、DO 閃一下 | IO 是「給誰」，DO 是「給什麼」。 |
| me 縮小消失，後面接上灰色 to me；a book 的標籤變成 O 🔊 He gave a book to me. | 東西也可以放前面，這時候，人的前面要加 to。 |
| to me 閃一下 | to me 變成修飾語， |
| 左上角標題變成「句型三：S + Vt + O」 | 句子就變成句型三：S + Vt + O。 |

### 段落 7　總整理

| 畫面 | 旁白／字幕 |
|---|---|
| 一張圖：三排「動詞後面接 0 塊／1 塊／2 塊」 | 最後整理一下：先找動詞，再數後面接幾塊。 |
| 第一排亮起 | 接 0 塊：句型一：S + Vi。 |
| 第二排亮起 | 接 1 塊：用等號試試看。 |
| 左格亮起（S ＝ SC） | 說得通，是句型二：S + V + SC。 |
| 右格亮起（S ≠ O） | 說不通，是句型三：S + Vt + O。 |
| 第三排亮起 | 接 2 塊：也用等號試試看。 |
| 左格亮起（O ＝ OC） | 說得通，是句型四：S + Vt + O + OC。 |
| 右格亮起（IO ≠ DO） | 說不通，是句型五：S + Vt + IO + DO。 |

### 段落 8　小測驗＋結尾

每一題：灰框積木出現 🔊 → 倒數 3 秒 → 積木上色、出現答案。

| 畫面 | 旁白／字幕 |
|---|---|
| 標題 | 來做小測驗！ |
| The cake tastes sweet. 🔊，倒數 | 這句是哪個句型？想一想。 |
| 上色、左上角出現答案 | 答案是句型二：S + V + SC。 |
| The cake ＝ sweet ✓ | 蛋糕＝甜的，說得通。 |
| My dad cooks dinner every night. 🔊 | 這句有修飾語，先把它拿掉。 |
| every night 縮小消失，倒數 | 是哪個句型呢？ |
| 上色、出現答案 | 答案是句型三：S + Vt + O。 |
| She sent me a card. 🔊，倒數 | 最後一題！ |
| 上色、出現答案 | 答案是句型五：S + Vt + IO + DO。 |
| me、a card 標上 1、2 | 先接人，再接東西。 |
| 結尾畫面 | 記住：先找動詞，再數後面接幾塊。 |
