# 五大句型教學影片：分鏡腳本

> 給英文初學者的教學影片，看完就懂「什麼是五大句型」。
> 橫式 1920×1080、約 4 分鐘；中文說明用字幕，英文例句用 Kokoro 語音（和網站朗讀同一個聲音）。
> 程式在 `video/`，每一段的資料在 `video/src/scenes.ts`。**改字幕或例句時，這份文件和 scenes.ts 要一起改。**

## 共同規則

- 句型編號採賴世雄版，**一律和公式一起出現**（例如「句型三：S + Vt + O」）。
- 積木顏色和網站一樣：S 藍、V 橘、O 綠、C 黃；修飾語灰色。
- 每個積木上方有小標籤（S、Vi、SC…），和網站分析頁的標法一致。
- 所有例句都用網站的分析程式跑過，結果和影片一致（2026-09-28 確認）。
- 字幕：每一行最多約 20 個中文字；每秒最多約 5 個字，初學者才看得完。
- 例句和字幕全部自己寫，不用文法書或其他影片的內容。

## 逐段腳本

「🔊」表示這時候唸英文例句。

### 段落 0　開場

| 畫面 | 字幕 |
|---|---|
| 長句子的積木一塊一塊出現（彩色＋灰色）🔊 | 這句英文好長，看起來好難？ |
| 灰色積木一塊一塊縮小消失 | 把灰色的部分拿掉⋯⋯ |
| 只剩 my little brother／reads／comic books 🔊 | 剩下的，就是句子的骨架。 |
| 大標題「五大句型」 | 英文句子再長，骨架只有五種。 |

### 段落 1　認識 4 種積木

| 畫面 | 字幕 |
|---|---|
| S 積木出現 | S 主詞：句子在說「誰」或「什麼」。 |
| V 積木出現 | V 動詞：主詞「做什麼」或「是什麼」。 |
| O 積木出現 | O 受詞：動作的對象。 |
| C 積木出現 | C 補語：補充說明主詞或受詞。 |
| 灰色積木出現 | 灰色是修飾語：說明時間、地點、方式。 |
| 灰色積木閃一下 | 修飾語拿掉，骨架還是完整的。 |
| 四種積木排成一排，V 後面出現「？」 | 關鍵：看動詞後面接了幾塊積木。 |

### 段落 2　句型一：S + Vi

| 畫面 | 字幕 |
|---|---|
| 大標題「句型一：S + Vi」，縮到左上角 | （無） |
| Birds、fly 掉下來 🔊，下方中譯「鳥會飛。」 | 動詞後面，什麼都不接。 |
| 下方出現「動詞後面：0 塊」 | 動詞說完，意思就完整了。 |
| 灰色 in the sky 接到後面 🔊 | 加上修飾語 in the sky（在天空）⋯⋯ |
| in the sky 縮小消失 | 拿掉也沒關係，句子還是完整的。 |
| fly 的標籤 Vi 閃一下 | Vi 是不及物動詞：後面不需要受詞。 |

### 段落 3　句型二：S + V + SC

| 畫面 | 字幕 |
|---|---|
| 大標題，縮到左上角 | （無） |
| She、is、a nurse 掉下來 🔊，中譯「她是護理師。」 | 動詞後面接 1 塊。 |
| a nurse 出現數字 1 | 這一塊是受詞，還是補語？ |
| 下方出現 She ＝ a nurse ✓ | 放一個等號：She ＝ a nurse，說得通！ |
| a nurse 的標籤 SC 閃一下 | 說得通，它就是補語 SC，說明主詞是什麼。 |

### 段落 4　句型三：S + Vt + O

| 畫面 | 字幕 |
|---|---|
| 大標題，縮到左上角 | （無） |
| I、like、music 掉下來 🔊，中譯「我喜歡音樂。」 | 動詞後面也接 1 塊。 |
| music 出現數字 1 | 這次是受詞，還是補語？ |
| 下方出現 I ≠ music ✗ | 放一個等號：I ＝ music？我不是音樂，說不通！ |
| music 的標籤 O 閃一下 | 說不通，它就是受詞 O：動作的對象。 |
| like 的標籤 Vt 閃一下 | Vt 是及物動詞：後面一定要有受詞。 |

### 段落 5　句型四：S + Vt + O + OC

| 畫面 | 字幕 |
|---|---|
| 大標題，縮到左上角 | （無） |
| The news、made、her、sad 掉下來 🔊，中譯「這個消息讓她很難過。」 | 動詞後面接 2 塊。 |
| her、sad 出現數字 1、2 | her 是受詞；sad 在說明 her。 |
| 下方出現 her ＝ sad ✓ | 放一個等號：her ＝ sad，她很難過，說得通！ |
| sad 的標籤 OC 閃一下 | 所以 sad 是受詞補語 OC，說明受詞怎麼樣。 |

### 段落 6　句型五：S + Vt + IO + DO

| 畫面 | 字幕 |
|---|---|
| 大標題，縮到左上角 | （無） |
| He、gave、me、a book 掉下來 🔊，中譯「他給我一本書。」 | 動詞後面也接 2 塊：先接「人」，再接「東西」。 |
| me、a book 出現數字 1、2 | 兩塊都是受詞嗎？ |
| 下方出現 me ≠ a book ✗ | 放一個等號：me ＝ a book？說不通！ |
| IO、DO 標籤閃一下 | 兩塊都是受詞：IO 是「給誰」，DO 是「給什麼」。 |
| me 縮小消失，後面接上灰色 to me；a book 的標籤變成 O 🔊 He gave a book to me. | 東西放前面，人就要用 to 帶出來。 |
| 左上角標題變成「句型三：S + Vt + O」 | to me 變成修飾語，句子就變成句型三：S + Vt + O。 |

### 段落 7　總整理

| 畫面 | 字幕 |
|---|---|
| 一張圖：三排「動詞後面接 0 塊／1 塊／2 塊」 | 最後整理：先找動詞，再看後面接幾塊。 |
| 第一排亮起：句型一：S + Vi | 接 0 塊：句型一：S + Vi。 |
| 第二排亮起：句型二：S + V + SC（S ＝ SC）、句型三：S + Vt + O（S ≠ O） | 接 1 塊：用等號分辨，＝ 是補語，≠ 是受詞。 |
| 第三排亮起：句型四：S + Vt + O + OC（O ＝ OC）、句型五：S + Vt + IO + DO（IO ≠ DO） | 接 2 塊：也用等號分辨。 |

### 段落 8　小測驗＋結尾

每一題：灰框積木出現 🔊 → 倒數 3 秒 → 積木上色、出現答案。

| 題目 | 字幕（倒數時） | 答案畫面與字幕 |
|---|---|---|
| The cake tastes sweet. | 小測驗：這句是哪個句型？ | 句型二：S + V + SC。The cake ＝ sweet，說得通。 |
| My dad cooks dinner every night. | 先把灰色的修飾語拿掉。 | 句型三：S + Vt + O。every night 是修飾語。 |
| She sent me a card. | 最後一題！ | 句型五：S + Vt + IO + DO。先接人，再接東西。 |
| 結尾 | 英文句子再長，先找動詞，再看後面接幾塊。 | 到「英文句子骨架分析」網站，練習更多句子！ |
