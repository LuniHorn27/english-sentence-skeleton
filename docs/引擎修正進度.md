## 怎麼看這張表

- **模型**：這一類預設派給誰。`sonnet`＝照著報告做就能完成；`opus`＝要動到資料結構或多個檔案；`fable`＝要看懂整個引擎才不會拆壞。修兩輪還不過，自動往上換一級（sonnet → opus → fable）。不用 haiku。
- **卡在**：寫著「決定 N」的，是〈引擎全面檢查-2026-11.md〉第七節第 N 項還沒決定，不能先做（表裡寫了「可先做」的部分除外）。
- **狀態**：`未開始`、`進行中（分支）`、`等合併（分支或 PR）`、`完成（日期、commit）`、`修不好（原因）`。
