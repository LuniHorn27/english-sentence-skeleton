# 品牌規範

做任何畫面、圖示、文案、簡報、社群圖之前先看這份。一句話總結：**一隻冷靜的偵探貓，陪你把句子的骨架找出來；畫面乾淨、只有骨架有顏色、說話像朋友不像補習班。**

## 一、品牌核心

**我們相信：每讀懂一個句子，就多打開一扇門。**

這個工具要解決的問題很具體：很多學生背了好幾年單字，拿到一段英文還是不知道從哪裡讀起，不是不夠努力，而是沒有人帶他們看見句子的骨架。

三個承諾，所有設計和文案都不能違背：

| 承諾 | 意思 | 會影響什麼 |
|---|---|---|
| 看見骨架 | 先抓主詞、動詞、受詞、補語，再看修飾 | 畫面只讓骨架有顏色，其他退到灰色 |
| 每個人都用得到 | 免費、不用註冊、城市偏鄉都一樣 | 不放付費牆、不做「會員限定」的字眼 |
| 誠實可信 | 程式會出錯就老實說，句子不保存 | 有「回報錯誤」、有隱私說明，不誇大準確度 |

## 二、角色：偵探貓

**為什麼是貓、為什麼是偵探：** 一般英文學習網站用書本、ABC、學士帽，看起來都像補習班。偵探貓有記憶點，而且「拿放大鏡找線索」剛好就是這個工具在做的事：在一長串英文裡找出 S、V、O、C。

**個性：** 冷靜、好奇、有點聰明，但不賣萌、不說教。它是陪你一起找線索的夥伴，不是站在講台上的老師。

**畫法（已定案，不要改）：**

- 藍色圓角方塊當底，白色貓頭，圓頭、耳尖微圓
- 只有兩隻黑眼睛和一個粉紅小鼻子，**沒有嘴巴、腮紅、睫毛、耳內粉紅**（試過可愛版，太甜，不採用）
- 右下角拿一支橘色放大鏡，鏡片裡四個色塊排成上二下二：左上 S 藍、右上 V 橘紅、左下 O 綠、右下 C 黃

**檔案：**

| 檔案 | 用途 |
|---|---|
| `frontend/favicon.svg` | 主檔，網頁分頁圖示、導覽列標誌、任何需要放大縮小的地方 |
| `frontend/favicon-32.png` | 不支援 SVG 的瀏覽器備用 |
| `frontend/apple-touch-icon.png` | 手機加到主畫面（180 px，直角正方形，系統會自己裁圓角） |

**使用規則：**

- 最小 16 px。32 px 以下鏡片裡的四色會糊成一團，這是可以接受的，不要為了小尺寸另外改圖
- 標誌周圍至少留標誌寬度的四分之一當空白
- 不要拉長壓扁、不要換底色、不要改四個色塊的順序、不要加外框或陰影
- 不要把貓拿掉只留放大鏡，也不要把放大鏡拿掉只留貓：兩個合起來才是「找骨架」
- 之後如果要做貓的其他表情或動作（例如找到答案時、出錯時），沿用同一套簡約畫法：只靠眼睛形狀和放大鏡位置表達，不加嘴巴和腮紅

## 三、顏色

### 主色

| 名稱 | 色碼 | 用在哪裡 |
|---|---|---|
| 主藍 | `#2f6fed` | 標誌底色、主要按鈕、連結 |
| 放大鏡橘 | `#e8a33d` | 只用在標誌的放大鏡 |
| 鼻子粉紅 | `#e8798f` | 只用在標誌的鼻子 |
| 墨黑 | `#1a1d23` | 文字、貓眼 |
| 背景灰白 | `#f7f8fa` | 淺色模式背景（深色模式 `#111317`） |

### 句子成分四色（品牌最重要的顏色）

S、V、O、C 四個顏色是這個品牌的核心辨識，網頁上標句子、五大句型頁、小遊戲、簡報、社群圖都要一致：**S 藍、V 橘紅、O 綠、C 黃（偏琥珀）**，順序永遠是 S → V → O → C。

同一個顏色有兩種濃度，用途不同：

| 成分 | 標誌和插圖用（鮮豔，小尺寸也看得到） | 網頁標記用（底色／字色／底線，見 `style.css`） |
|---|---|---|
| S 主詞 | `#2f6fed` | `#e6f1fb`／`#0c447c`／`#185fa5` |
| V 動詞 | `#e0603a` | `#faece7`／`#712b13`／`#993c1d` |
| O 受詞 | `#1a9a74` | `#e1f5ee`／`#085041`／`#0f6e56` |
| C 補語 | `#f2b52b` | `#faeeda`／`#633806`／`#854f0b` |

深色模式的網頁標記用色另外定義在 `style.css` 的深色區塊，不要自己調。

**規則：** 這四個顏色只拿來代表 S、V、O、C，不要拿去當裝飾、按鈕或分類標籤，否則學生會搞混「綠色到底是不是受詞」。修飾語一律用灰色。

## 四、字體

- 中文和英文都用系統字體：蘋果裝置是蘋方（PingFang TC），其他是思源黑體（Noto Sans TC）或微軟正黑體
- 不另外載入網路字體（免費、載入快、偏鄉網路慢也不受影響）
- 標題用粗體，內文用一般粗細；不要用斜體表示強調，中文斜體很難看

## 五、說話方式

**像一個會英文、講話直接的學長姐，不像補習班老師。**

| 要 | 不要 |
|---|---|
| 先講結論，再講理由 | 一開頭鋪陳一大段 |
| 白話、台灣常用說法，可以偶爾用台語感的口語（「看攏無」「落落長」） | 文法術語不解釋就直接用 |
| 用到術語時順便說明（「補語，就是補充說明主詞或受詞的字」） | 「必考」「秒懂」「保證」「速成」這類補習班廣告用語 |
| 鼓勵但不吹捧（「這句比較長，我們一段一段拆」） | 「你好棒！」「太厲害了！」 |
| 出錯時老實說，並告訴使用者可以怎麼做 | 把錯推給使用者，或假裝不會出錯 |

**寫作格式：**

- 台灣繁體中文，中文句子用全形標點（，。：；「」？！），英文和程式碼維持半形
- 提到句型一定寫「句型號碼＋公式」，例如「句型三 S＋Vt＋O」，不要只寫「句型三」；複句用 ＆ 連接
- 句型編號依賴世雄／常春藤：句型一 S＋Vi、句型二 S＋Vi＋SC、句型三 S＋Vt＋O、句型四 S＋Vt＋O＋OC、句型五 S＋Vt＋IO＋DO

**範例（網站現有文案，風格可參考）：**

- 「句子落落長看不懂？」
- 「每個字都認識，合起來卻看攏無？」
- 「分析結果由程式自動產生，僅供學習參考，可能會有錯誤。」

## 六、畫面原則

- **乾淨優先。** 分析結果是主角，其他功能（回饋、分享、贊助）縮小放在旁邊或下方
- **只有骨架有顏色。** 主要成分用四色，修飾語用灰色加文字標籤，不用色塊和箭頭（試過，太亂）
- **先骨架、後細節。** 預設顯示骨架，細節要使用者自己點開
- **不加裝飾。** 不用漸層、毛玻璃、彩虹按鈕、卡通插圖填空白；偵探貓是唯一的角色，不要再加別的吉祥物
- **手機和電腦都要好用**，手機畫面左右至少留 16 px
