# 品牌規範

做任何畫面、圖示、文案、簡報、社群圖之前先看這份。一句話總結：**一隻長得很正經、講話很白爛的偵探貓，陪你把句子的骨架找出來；畫面乾淨、只有骨架有顏色，文法講得清清楚楚，其他時候盡量耍廢。**

## 一、品牌核心

**我們相信：每讀懂一個句子，就多打開一扇門。**

這個工具要解決的問題很具體：很多學生背了好幾年單字，拿到一段英文還是不知道從哪裡讀起，不是不夠努力，而是沒有人帶他們看見句子的骨架。

三個承諾，所有設計和文案都不能違背：

| 承諾 | 意思 | 會影響什麼 |
|---|---|---|
| 看見骨架 | 先抓主詞、動詞、受詞、補語，再看修飾 | 畫面只讓骨架有顏色，其他退到灰色 |
| 每個人都用得到 | 免費、不用註冊、城市偏鄉都一樣 | 不放付費牆、不做「會員限定」的字眼 |
| 誠實可信 | 程式會出錯就老實說，句子不保存 | 有「回報錯誤」、有隱私說明，不誇大準確度 |

## 二、角色：偵探貓

**為什麼是貓、為什麼是偵探：** 一般英文學習網站用書本、ABC、學士帽，看起來都像補習班。偵探貓有記憶點，而且「拿放大鏡找線索」剛好就是這個工具在做的事：在一長串英文裡找出 S、V、O、C。

**標誌只負責「認得出這隻貓」，S/V/O/C 交給網站內容。** 標誌試過在放大鏡裡放四色色塊，但 16 px 分頁圖示上四色會糊成一團，反而讓貓變難認，所以最後選了「放大鏡蓋住一隻眼睛、把眼睛放大」的版本：小尺寸最好認，也最有個性。句子分析的聯想由網站上的四色標記、五大句型頁、社群圖來建立。

**個性：** 外表冷靜，一開口很白爛。愛裝偵探腔、愛吐槽自己、偶爾很中二，但不賣萌、不說教，也不嘲笑使用者。它是陪你一起找線索的損友，不是站在講台上的老師。外表簡約、講話白爛，這個反差就是記憶點，所以圖要繼續簡約，好笑的部分交給文字。

**畫法（已定案，不要改）：**

- 藍色圓角方塊當底，白色貓頭，尖耳朵
- 左眼是一顆小黑眼；右眼被一支黑框放大鏡蓋住，鏡片是奶油色，裡面是一顆被放大的大眼睛（黑色瞳孔加一個白色反光點）
- 一個粉紅小鼻子，**沒有嘴巴、腮紅、睫毛、耳內粉紅**（試過可愛版，太甜，不採用）
- 放大鏡的握柄往右下角伸出貓頭外
- 笑點就在「一大一小的眼睛」：正經地盯著你看，又有點白爛

**檔案：**

| 檔案 | 用途 |
|---|---|
| `frontend/favicon.svg` | 主檔，網頁分頁圖示、導覽列標誌、任何需要放大縮小的地方 |
| `frontend/favicon-32.png` | 不支援 SVG 的瀏覽器備用 |
| `frontend/apple-touch-icon.png` | 手機加到主畫面（180 px，直角正方形，系統會自己裁圓角） |

**使用規則：**

- 最小 16 px，這個尺寸也認得出白貓和放大鏡，不要為了小尺寸另外改圖
- 標誌周圍至少留標誌寬度的四分之一當空白
- 不要拉長壓扁、不要換底色、不要加外框或陰影
- 不要在標誌裡加 S/V/O/C 色塊或字母；需要同時表達句子分析時（例如簡報封面、社群圖），把四色放在標誌旁邊，不要塞進標誌裡
- 不要把貓拿掉只留放大鏡，也不要把放大鏡拿掉只留貓：被放大的那隻眼睛就是這隻貓的招牌
- 之後如果要做貓的其他表情或動作（例如找到答案時、出錯時），沿用同一套簡約畫法：只靠眼睛形狀和放大鏡位置表達（例如鏡片裡的眼睛瞇起來、瞪大、變成問號），不加嘴巴和腮紅

## 三、顏色

### 主色

| 名稱 | 色碼 | 用在哪裡 |
|---|---|---|
| 主藍 | `#2f6fed` | 標誌底色、主要按鈕、連結 |
| 鏡片奶油 | `#fdf3e1` | 只用在標誌的放大鏡鏡片 |
| 鼻子粉紅 | `#e88aa0` | 只用在標誌的鼻子 |
| 墨黑 | `#1a1d23` | 文字、貓眼、放大鏡框和握柄 |
| 背景灰白 | `#f7f8fa` | 淺色模式背景（深色模式 `#111317`） |

### 句子成分四色（品牌最重要的顏色）

S、V、O、C 四個顏色是這個品牌在內容上的核心辨識（標誌本身不用這四色），網頁上標句子、五大句型頁、小遊戲、簡報、社群圖都要一致：**S 藍、V 橘紅、O 綠、C 黃（偏琥珀）**，順序永遠是 S → V → O → C。

同一個顏色有兩種濃度，用途不同：

| 成分 | 插圖、簡報、社群圖用（鮮豔，小尺寸也看得到） | 網頁標記用（底色／字色／底線，見 `style.css`） |
|---|---|---|
| S 主詞 | `#2f6fed` | `#e6f1fb`／`#0c447c`／`#185fa5` |
| V 動詞 | `#e0603a` | `#faece7`／`#712b13`／`#993c1d` |
| O 受詞 | `#1a9a74` | `#e1f5ee`／`#085041`／`#0f6e56` |
| C 補語 | `#f2b52b` | `#faeeda`／`#633806`／`#854f0b` |

深色模式的網頁標記用色另外定義在 `style.css` 的深色區塊，不要自己調。

**規則：** 這四個顏色只拿來代表 S、V、O、C，不要拿去當裝飾、按鈕或分類標籤，否則學生會搞混「綠色到底是不是受詞」。修飾語一律用灰色。

## 四、字體

- 中文和英文都用系統字體：蘋果裝置是蘋方（PingFang TC），其他是思源黑體（Noto Sans TC）或微軟正黑體
- 不另外載入網路字體（免費、載入快、偏鄉網路慢也不受影響）
- 標題用粗體，內文用一般粗細；不要用斜體表示強調，中文斜體很難看

## 五、說話方式

**像一隻白爛的貓：自稱「本貓」，愛裝偵探、愛自嘲，但講到文法就突然很可靠。**

白爛是調味料，不是主菜。分得清楚什麼時候可以耍白爛、什麼時候要正經：

| 場合 | 語氣 | 例子 |
|---|---|---|
| 首頁標語、等待中、空白狀態 | 盡量白爛 | 「本貓辦案中，請勿打擾……」 |
| 分析完成、小遊戲回饋 | 白爛一句，接著講重點 | 「破案。這句的兇手是 showed，句型五 S＋Vt＋IO＋DO。」 |
| 出錯、伺服器出問題 | 白爛自嘲，但一定說清楚怎麼辦 | 「本貓看走眼了，這句可能拆錯。按『回報錯誤』，本貓回去罰站。」 |
| 文法說明、文法重點卡、五大句型頁 | 正經、清楚，最多開頭一句玩笑 | 內文照第五節下方的寫作格式 |
| 隱私說明、法律相關、回報表單 | 完全正經 | 「你輸入的句子只用來當下分析，不會被保存。」 |

**白爛的界線：**

| 可以 | 不可以 |
|---|---|
| 吐槽自己（本貓眼殘、本貓要去罰站） | 吐槽使用者（「這都不會？」「你是認真的嗎」） |
| 偵探梗、貓梗（破案、兇手、線索、打翻杯子、踩鍵盤） | 嘲笑答錯、拿成績或程度開玩笑 |
| 台灣口語、台語感的詞（「看攏無」「落落長」「欸不是」） | 髒話、注音文、火星文、很快會過時的網路流行語 |
| 一句話一個梗 | 梗疊梗，讓人找不到重點 |
| 錯了就認，順便自嘲 | 用玩笑帶過錯誤、假裝不會出錯 |
| 白話解釋術語（「補語，就是補充說明主詞或受詞的字」） | 「必考」「秒懂」「保證」「速成」這類補習班廣告用語 |

**更多語氣範例（還沒放進網站，用到時要先給使用者看過）：**

- 還沒輸入句子就按分析：「你什麼都沒貼，本貓的放大鏡對著空氣很尷尬。」
- 句子太長：「這句長到本貓的放大鏡起霧了，要不要先拆成幾句？」
- 伺服器休眠中：「伺服器在午睡，本貓去踹它，等我 30 秒。」
- 小遊戲答對：「可以喔，你比本貓還會辦案。」
- 小遊戲答錯：「欸不是，再看一次動詞後面跟了誰。」

**寫作格式（不管白不白爛都要遵守）：**

- 台灣繁體中文，中文句子用全形標點（，。：；「」？！），英文和程式碼維持半形
- 提到句型一定寫「句型號碼＋公式」，例如「句型三 S＋Vt＋O」，不要只寫「句型三」；複句用 ＆ 連接
- 句型編號依賴世雄／常春藤：句型一 S＋Vi、句型二 S＋Vi＋SC、句型三 S＋Vt＋O、句型四 S＋Vt＋O＋OC、句型五 S＋Vt＋IO＋DO
- 先講結論，再講理由

## 六、畫面原則

- **乾淨優先。** 分析結果是主角，其他功能（回饋、分享、贊助）縮小放在旁邊或下方
- **只有骨架有顏色。** 主要成分用四色，修飾語用灰色加文字標籤，不用色塊和箭頭（試過，太亂）
- **先骨架、後細節。** 預設顯示骨架，細節要使用者自己點開
- **不加裝飾。** 不用漸層、毛玻璃、彩虹按鈕、卡通插圖填空白；偵探貓是唯一的角色，不要再加別的吉祥物
- **手機和電腦都要好用**，手機畫面左右至少留 16 px

4. 貓自稱「本貓」，以及「破案」「兇手」這類偵探梗，是我依「白爛的貓」推出來的。
5. 網站現有文案（按鈕、提示、錯誤訊息）要不要改成白爛語氣、改哪些，還沒決定；改之前要先給你看。
6. 第二節「需要表達句子分析時，四色放在標誌旁邊」是我推出來的用法，還沒有實際做過。
