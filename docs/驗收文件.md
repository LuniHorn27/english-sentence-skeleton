# 驗收文件：英文句子骨架分析

> 驗收日期：2026-09-28　驗收人：Claude（開發者自我驗收）　版本：GitHub main 分支（本文件提交時的版本）
> 這是開發者自己做的驗收，**不能取代你（使用者）的試用驗收**；第六節列出需要你親自確認的項目。

## 結論

**功能面：通過。** 30 項自動驗收檢查在本機和外部網址都是 30／30 通過；分析測試題庫 140 句全部正確；45 句怪異輸入沒有任何一句讓程式當掉；手機寬度下所有頁面都沒有超出螢幕。

**還不能算「正式上線」**，有三件事沒完成：

1. **沒有固定網址**：目前是從你的 Mac 開的臨時網址，Mac 睡眠或斷網就會失效，網址也會變。正式主機還沒決定（Oracle 註冊被擋）。
2. **回饋試算表還沒設定**：程式寫好了，要你建立 Google 試算表（約 5 分鐘）。
3. **你還沒完整試用過最新版**：朗讀的聲音、翻譯品質、畫面好不好用，只有你能判斷。

## 五、已知限制與風險

| # | 限制或風險 | 影響 | 建議 |
|---|---|---|---|
| 1 | 臨時網址依賴你的 Mac：睡眠、斷網就失效，網址會變 | 別人隨時可能連不上 | 決定正式主機（待審核清單第 59 項） |
| 2 | 分析準確度是用**我自己出或整理的題庫**測的；真實使用者的句子更多樣 | 長句、少見句型仍可能分析錯 | 靠「回報錯誤」持續修正 |
| 3 | 考試題已隨 GitHub 公開，不再是外人沒看過的題目 | 對「我寫規則時不看考試題」沒有影響 | 無 |
| 4 | 翻譯是機器翻譯，已標「機器翻譯」 | 偶爾不通順或錯 | 使用者可回報 |
| 5 | 翻譯一次只能翻一句，很多人同時用時要排隊 | 人多時翻譯變慢（分析不受影響） | 正式主機若 CPU 較多可調整 |
| 6 | 字典意思的順序照 ECDICT 原本的順序，例如 give 會先列「n. 彈性」 | 少數字要往後看才找到常用意思 | 之後可依句子裡的詞性排序 |
| 7 | 片語可能和字面意思混淆（*run into the room*） | 片語卡已提醒「也可能是字面意思」 | 無 |
| 8 | Dockerfile 沒有實際建置過（這台 Mac 沒有 Docker） | 搬到雲端主機時可能要小修 | 上線時看建置紀錄 |
| 9 | 瀏覽器內建翻譯（伺服器翻譯壞掉時的備用）沒有在真正的 Chrome 測過 | 只有伺服器翻譯壞掉時才會用到 | 低優先 |

## 六、需要你親自驗收的項目

請用**手機**和**電腦**各試一次，覺得不對就按「回報錯誤」或直接告訴我：

- [ ] 貼一段課本文章（5 句以上），看版面是否清楚、中文翻譯是否好找
- [ ] 按「🔊 朗讀」，聲音是否自然
- [ ] 點幾個片段，看說明和「📖 單字」是否有幫助
- [ ] 五大句型頁從頭讀到尾，初學者看不看得懂
- [ ] 兩種小遊戲各玩一回合，題目和翻譯有沒有問題
- [ ] 在「一起讓它更好」送一則，試算表有沒有新增一行、Gmail 有沒有收到通知信
- [ ] 關於頁的文字是否符合你的想法
- [ ] 學習資源草稿（http://127.0.0.1:8765/resources ）要不要公開、要不要增減
