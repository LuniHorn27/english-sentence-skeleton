# 資安檢查與上架規劃（2026-10-01 夜間）

## 先講結論

**資安**：目前沒有嚴重的漏洞。網站不存帳號密碼、不收個人資料，使用者輸入的句子一律當純文字顯示，機密（試算表網址）沒有進 GitHub。這一晚補了三個缺口（安全標頭、請求大小上限、次數限制的記憶體清理），剩下兩個風險要等上線前處理：**同時太多人分析時伺服器會被拖慢**，以及**套件漏洞沒有定期檢查**。

**上架**：我建議分兩步走。
1. **先用「你的 Mac＋Cloudflare 固定網址」**：花一個網域的錢（每年約 300～500 元台幣），網址就不會再每次換掉。缺點是 Mac 要一直開著。適合先給少數老師、學生試用。
2. **使用者變多後，搬到 Hetzner 的主機**（8 GB 記憶體，每月約 6.5 歐元，約 230 元台幣），Mac 就不用開著。

免費的雲端方案（Hugging Face、Oracle、Google Cloud Run）我都查過，目前都不適合，原因在下面。

## 二、資安檢查

### 已經做得不錯的地方

| 項目 | 現況 |
|---|---|
| 使用者輸入的句子 | 畫面一律用純文字顯示，貼 HTML 或程式碼進來也不會被執行 |
| 文法卡 | 只允許粗體 `<b>`，其他標籤都會被轉成文字 |
| 隱私 | 不需要登入；伺服器不記錄句子內容（錯誤紀錄只記長度）；朗讀用 POST，句子不會出現在網址紀錄；伺服器存取紀錄關閉 |
| 回饋 | 只送到你的 Google 試算表，不在主機留備份；網址必須是 script.google.com 開頭才會送 |
| 管理頁（回饋清單、學習資源草稿） | 只有在執行網站的電腦上直接打開才看得到；從網路進來、或偽裝成本機的請求一律顯示「找不到」（已實際測試） |
| 文法卡的網址 | 不能用 `../` 讀取其他檔案（已實際測試） |
| 次數限制 | 分析每分鐘 30 次、翻譯 60 次、朗讀 60 次、查單字 120 次、回饋每小時 20 則 |
| 機密外洩 | 翻過整個 git 歷史，沒有試算表網址、密碼、金鑰；`data/`、`models/`、課本照片都設定成不上傳 |
| 經過 Cloudflare 時的來源位址 | 伺服器只相信本機（Cloudflare 通道）轉過來的來源位址，外面的人偽造「我是某某 IP」沒有用 |

### 這一晚補上的（已完成、已測試）

1. **瀏覽器安全標頭**：只准載入本站自己的程式和樣式（防止被塞入惡意程式）、不能被嵌進別人的網頁（防止「點擊劫持」）、點外部連結時不透露網址（分享連結裡有句子）。已確認分析、翻譯、朗讀、文法卡、小遊戲都正常。
2. **請求大小上限 200 KB**：原本「回報錯誤」附帶的分析結果沒有大小限制，有心人可以送幾百 MB 的資料拖慢伺服器。
3. **次數限制的紀錄定期清理**：原本每個來源的紀錄用過不會刪，來源一多記憶體會一直增加。

### 還有的風險（建議上線前處理）

| 風險 | 說明 | 建議 | 需要你決定嗎 |
|---|---|---|---|
| 同時太多人分析 | 分析一句約 0.1～0.5 秒，但沒有「同時最多幾個」的限制；很多人同時貼長文章時，伺服器會變慢，翻譯也會排隊 | 加一個「同時最多分析 2 份」的排隊機制，排太久就顯示「目前使用的人比較多，請稍後再試」 | 是（會多一個畫面提示文字） |
| 套件漏洞 | 使用的套件（FastAPI、torch、transformers…）偶爾會公布漏洞，目前沒有定期檢查 | 上線前裝 `pip-audit` 檢查一次，之後每月一次；GitHub 也可以開 Dependabot 自動提醒 | 是（要下載工具） |
| 翻譯模型亂講話 | 翻譯是 AI 產生的，極少數情況可能翻出奇怪的內容 | 畫面已標「機器翻譯」；維持現狀即可 | 否 |
| Cloudflare 臨時網址 | 任何人拿到網址都能用；網址每次開機會換 | 換成固定網址（見上架規劃） | 是 |
| Mac 當伺服器 | 網站跑在你的 Mac 上，萬一網站程式有漏洞，影響的是你的電腦 | 伺服器只開在本機、經過 Cloudflare 才對外，已經是比較安全的做法；長期建議搬到獨立主機 | 見上架規劃 |

## 三、上架規劃

### 網站需要多少資源

實際量過：網站執行時約用 **6 GB 記憶體**（分析程式約 1.5 GB、翻譯模型 Qwen3-4B 約 3～4 GB、朗讀模型約 0.5 GB），模型檔共 2.7 GB。所以主機要 **8 GB 記憶體以上**。如果拿掉伺服器上的翻譯（改用瀏覽器內建翻譯），降到約 2～3 GB，選擇就會多很多。

### 方案比較

| 方案 | 費用 | 優點 | 缺點 |
|---|---|---|---|
| **A. Mac＋Cloudflare 臨時網址**（目前） | 免費 | 已經在用 | 網址每次會變；Mac 睡眠或關機就斷線 |
| **B. Mac＋Cloudflare 固定網址**（建議第一步） | 網域每年約 300～500 元 | 網址固定（例如 skeleton.你的網域.com）；設定一次就好 | Mac 還是要一直開著 |
| **C. Hetzner 主機 CX33**（建議第二步） | 每月約 6.5 歐元（約 230 元），4 核心、8 GB | 不用開 Mac；便宜；速度穩定 | 要我幫你設定一次；主機在歐洲，台灣連線稍慢（約 0.2～0.3 秒延遲，分析本身影響不大） |
| D. Oracle 免費主機 | 免費 | 免費 | 你之前註冊被擋；2026 年 6 月起新帳號免費額度砍半成 12 GB，勉強夠用 |
| E. Hugging Face Spaces | 每月 9 美元 | 設定簡單 | 免費帳號已經不能開這種 Space；錢比 Hetzner 多 |
| F. Google Cloud Run | 超過免費額度就要錢 | 沒人用時不收錢 | 每次冷啟動要載入 2.7 GB 模型，第一個人要等很久；免費額度換算下來每月只夠跑十幾個小時 |

### 我的建議

1. **現在**：選方案 B。你需要做的：買一個網域（Cloudflare、Namecheap、Gandi 都可以），並在 Cloudflare 開免費帳號。其他設定我來做。
2. **有穩定的使用者後**（例如一整班學生每天用）：搬到方案 C。你需要做的：註冊 Hetzner、綁信用卡。其他設定我來做。
3. **上線前一定要做的**：
   - 加上「同時最多分析 2 份」的排隊機制（見資安風險表）。
   - 跑一次套件漏洞檢查。
   - 關於頁補上隱私說明：不需登入、不記錄句子、回饋只給作者看。
   - 決定要不要保留伺服器上的翻譯：保留要 8 GB 主機；拿掉可以用更小、更便宜的主機，但翻譯品質要看使用者的瀏覽器（Chrome 才有）。
