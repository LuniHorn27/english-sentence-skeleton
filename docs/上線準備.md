> 狀態：**準備好了，但還沒上線**。程式碼已放在 GitHub（https://github.com/LuniHorn27/english-sentence-skeleton ），上線到 Hugging Face 需要你先註冊帳號（見下方步驟）。

## 建議的免費主機：Hugging Face Spaces

| 項目 | 說明 |
|---|---|
| 費用 | 免費（CPU Basic：2 核心、16 GB 記憶體），我們的分析程式需要約 2 GB，足夠 |
| 方式 | 用專案裡的 `Dockerfile` 建置 |
| 網址 | `https://<你的帳號>-<名稱>.hf.space` |
| 缺點 | 一段時間沒人用會休眠，下一個人打開時要等 1～2 分鐘啟動 |

## 上線前需要你決定的事

1. **帳號與網址**：用哪個帳號、網站叫什麼名字。
2. **使用者回饋要存在哪裡？** 目前存在伺服器上的檔案；但 Hugging Face 免費版重新啟動時，檔案會**消失**。選項：
   - A. Google 表單＋試算表（免費，你可以直接在試算表上看）
   - B. Hugging Face 的資料集（免費，需要多設定一個存取金鑰）
   - C. 付費的永久儲存空間
3. **關於頁面、隱私說明**的最終文字（草稿已經寫好，見「關於這個工具」頁面）。

## 上線步驟

> 為什麼不用 GitHub Pages：Pages 只能放靜態網頁，不能執行分析、翻譯、朗讀的程式。

**你要做的（約 10 分鐘）**

1. 到 https://huggingface.co 註冊帳號，並完成 email 驗證。
2. 右上角「New」→「Space」：
   - Space name：`english-sentence-skeleton`
   - SDK：**Docker**（範本選 Blank）
   - Hardware：CPU basic（免費）
   - 公開：Public
3. 右上角頭像 →「Settings」→「Access Tokens」→ 建立一個 **Write** 權限的金鑰（token）。
4. 在終端機執行下面這行，貼上剛才的金鑰。金鑰只存在你的電腦，不要貼在對話裡：

```bash
~/Desktop/english/.venv/bin/hf auth login --add-to-git-credential
```

5. 告訴我你的 Hugging Face 帳號名稱。

**我接著做的**

1. 把程式推送到 Space：`git push` 到 `https://huggingface.co/spaces/<帳號>/english-sentence-skeleton`
2. 看建置紀錄（第一次約 20～40 分鐘：要編譯翻譯程式、下載約 4 GB 的模型）
3. 打開網址 `https://<帳號>-english-sentence-skeleton.hf.space` 測試分析、翻譯、朗讀、回饋、手機版

**上線後要知道的**

- 一段時間沒人用會休眠，下一個人打開時要等 1～2 分鐘啟動。
- 免費版重新啟動時，「回報錯誤」存的檔案會消失（見上面「需要你決定的事」第 2 點）；測試期間可以先這樣。
- 翻譯在免費主機上每句約 2～5 秒。
