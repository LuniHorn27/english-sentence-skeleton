## 目前採用：A. 用 Mac 開臨時網址（2026-09-27 使用者選擇）

cloudflared 已用 Homebrew 安裝（`brew install cloudflared`，移除用 `brew uninstall cloudflared`）。開兩個終端機分頁，各執行一行：

```bash
cd ~/Desktop/english && .venv/bin/uvicorn backend.app:app --port 8765 --proxy-headers --forwarded-allow-ips 127.0.0.1 --no-access-log
```

```bash
cloudflared tunnel --no-autoupdate --url http://127.0.0.1:8765
```

- 第二行會印出 `https://….trycloudflare.com`，這就是測試網址；**每次重開都會變**。
- `--proxy-headers`：讓次數限制看到每個使用者真正的來源位址（不然所有人共用同一個限制）。
- `--no-access-log`：不記錄訪客的連線紀錄（IP 位址），符合關於頁的隱私說明。
- 不要加 `--reload`：改程式時伺服器會自動重啟，測試的人會斷線；要讓改動生效時再手動重啟。
- Mac 睡眠、關機或關掉任一個終端機分頁，網址就連不上。
- 回報錯誤存在這台 Mac 的 `data/feedback.jsonl`，用 `.venv/bin/python tools/show_feedback.py` 查看。

## 上線步驟

> 為什麼不用 GitHub Pages：Pages 只能放靜態網頁，不能執行分析、翻譯、朗讀的程式。

**你要做的（約 10 分鐘）**

1. 到 https://huggingface.co 註冊帳號，並完成 email 驗證。
2. 右上角「New」→「Space」：
   - Space name：`english-sentence-skeleton`
   - SDK：**Docker**（範本選 Blank）
   - Hardware：CPU basic（免費）
   - 公開：Public
3. 右上角頭像 →「Settings」→「Access Tokens」→ 建立一個 **Write** 權限的金鑰（token）。
4. 在終端機執行下面這行，貼上剛才的金鑰。金鑰只存在你的電腦，不要貼在對話裡：

```bash
~/Desktop/english/.venv/bin/hf auth login --add-to-git-credential
```

5. 告訴我你的 Hugging Face 帳號名稱。

**我接著做的**

1. 把程式推送到 Space：`git push` 到 `https://huggingface.co/spaces/<帳號>/english-sentence-skeleton`
2. 看建置紀錄（第一次約 20～40 分鐘：要編譯翻譯程式、下載約 4 GB 的模型）
3. 打開網址 `https://<帳號>-english-sentence-skeleton.hf.space` 測試分析、翻譯、朗讀、回饋、手機版

**上線後要知道的**

- 一段時間沒人用會休眠，下一個人打開時要等 1～2 分鐘啟動。
- 免費版重新啟動時，「回報錯誤」存的檔案會消失（見上面「需要你決定的事」第 2 點）；測試期間可以先這樣。
- 翻譯在免費主機上每句約 2～5 秒。
