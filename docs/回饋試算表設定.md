# 回饋試算表設定（回報錯誤、「一起讓它更好」→ Google 試算表）

> 設定一次，之後每一則「回報錯誤」和「一起讓它更好」的回饋都會自動變成試算表的一行。
> 試算表在你自己的 Google 帳號裡，只有你看得到。本機的 `data/feedback.jsonl` 仍然會保留一份備份。

## 你要做的（約 5 分鐘）

1. 打開 Claude 幫你建好的試算表「英文句子骨架分析：回饋」（在你的 Google 雲端硬碟）。如果還沒有，就到 https://sheets.new 建一個新的。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上下面這段程式，按上方的 💾 儲存：

```javascript
// 收到網站送來的回饋，就在第一個工作表加一行
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  // 第一行放欄位標題；不對的話（例如舊版多了「類別」欄）自動換成正確的
  const header = ["時間", "種類", "句子", "哪裡", "目前的分析", "內容"];
  const first = sheet.getRange(1, 1, 1, header.length + 1).getValues()[0];
  if (first.slice(0, header.length).join() !== header.join() || first[header.length] !== "") {
    sheet.getRange(1, 1, 1, sheet.getMaxColumns()).clearContent();
    sheet.getRange(1, 1, 1, header.length).setValues([header]);
    sheet.setFrozenRows(1);
  }
  const r = JSON.parse(e.postData.contents);
  // 內容開頭是 = + - @ 時加上 '，避免被試算表當成公式執行
  const safe = (v) => {
    const s = String(v || "").slice(0, 2000);
    return /^[=+\-@]/.test(s) ? "'" + s : s;
  };
  sheet.appendRow([
    new Date(r.time),
    r.kind === "error" ? "回報錯誤" : "一起讓它更好",
    safe(r.sentence), safe(r.part), safe(r.current), safe(r.message),
  ]);
  return ContentService.createTextOutput("ok");
}
```

4. 右上角 **部署 → 新增部署作業**：
   - 左邊齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網站伺服器要能送資料進來；別人沒有網址就送不進來，也看不到試算表內容）
   - 按 **部署**，第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。這是 Google 對自己寫的小程式的標準提醒。
5. 複製畫面上的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`），貼給 Claude。

## Claude 接著做的

- 把網址存到 `data/feedback_sheet.json`（`data/` 不會上傳到 GitHub，網址不會公開）。
- 重啟網站，送一則測試回饋，確認試算表有新增一行，再把測試那一行刪掉。

## 注意

- **網址要保密**：知道網址的人可以往試算表裡寫東西（但看不到內容）。只存在 `data/feedback_sheet.json`，不要貼到公開的地方。
- 如果之後改了 Apps Script 的程式，要重新「管理部署作業 → 編輯 → 新版本」，網址不會變。
- 送到試算表失敗時（例如網路斷線），回饋仍然會存在本機檔案，網站不會出錯。
- 以後網站搬到雲端主機時，把網址設成環境變數 `FEEDBACK_SHEET_URL` 就好。
