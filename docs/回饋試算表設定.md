# 回饋試算表設定（回報錯誤、「一起讓它更好」→ Google 試算表）

> 設定一次，之後每一則「回報錯誤」和「一起讓它更好」的回饋都會自動變成試算表的一行。
> 試算表在你自己的 Google 帳號裡，只有你看得到。本機的 `data/feedback.jsonl` 仍然會保留一份備份。

## 你要做的（約 5 分鐘）

1. 打開 Claude 幫你建好的試算表「英文句子骨架分析：回饋」（在你的 Google 雲端硬碟）。如果還沒有，就到 https://sheets.new 建一個新的。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上下面這段程式，按上方的 💾 儲存（**不用按「執行」**，直接執行一定會出現 postData 的錯誤，這是正常的）：

```javascript
// 收到網站送來的回饋：寫進試算表，並寄 email 通知你
//   第一個工作表「一起讓它更好」、第二個工作表「回報錯誤」（沒有的話自動建立）
const SHEETS = {
  suggestion: { name: "一起讓它更好", header: ["時間", "內容"] },
  error: { name: "回報錯誤", header: ["時間", "句子", "哪裡", "目前的分析", "你認為正確的是"] },
};

function getSheet(kind) {
  const book = SpreadsheetApp.getActiveSpreadsheet();
  const cfg = SHEETS[kind] || SHEETS.suggestion;
  let sheet = book.getSheetByName(cfg.name);
  if (!sheet && kind !== "error") {
    sheet = book.getSheets()[0];  // 第一個工作表改名成「一起讓它更好」
    sheet.setName(cfg.name);
  }
  if (!sheet) sheet = book.insertSheet(cfg.name, 1);  // 「回報錯誤」放在第二頁
  // 第一行放欄位標題；不對的話自動換成正確的
  const n = cfg.header.length;
  const first = sheet.getRange(1, 1, 1, n + 1).getValues()[0];
  if (first.slice(0, n).join() !== cfg.header.join() || first[n] !== "") {
    sheet.getRange(1, 1, 1, sheet.getMaxColumns()).clearContent();
    sheet.getRange(1, 1, 1, n).setValues([cfg.header]);
    sheet.setFrozenRows(1);
  }
  return sheet;
}

function doPost(e) {
  const r = JSON.parse(e.postData.contents);
  // 內容開頭是 = + - @ 時加上 '，避免被試算表當成公式執行
  const safe = (v) => {
    const s = String(v || "").slice(0, 2000);
    return /^[=+\-@]/.test(s) ? "'" + s : s;
  };
  const time = Utilities.formatDate(new Date(r.time), "Asia/Taipei", "yyyy/MM/dd HH:mm");  // 台灣時間
  if (r.kind === "error") {
    getSheet("error").appendRow([time, safe(r.sentence), safe(r.part), safe(r.current), safe(r.message)]);
  } else {
    getSheet("suggestion").appendRow([time, safe(r.message)]);
  }
  notify(r, time);
  return ContentService.createTextOutput("ok");
}

// 寄一封純文字 email 給試算表的擁有者（就是你）；寄信失敗不影響寫進試算表
function notify(r, time) {
  try {
    const clip = (v) => String(v || "").slice(0, 2000);
    const isError = r.kind === "error";
    const subject = isError ? "【英文句子骨架分析】新的回報錯誤" : "【英文句子骨架分析】新的回饋";
    const lines = isError
      ? ["時間：" + time, "句子：" + clip(r.sentence), "哪裡：" + clip(r.part), "目前的分析：" + clip(r.current), "你認為正確的是：" + clip(r.message)]
      : ["時間：" + time, "內容：" + clip(r.message)];
    lines.push("", "所有回饋：" + SpreadsheetApp.getActiveSpreadsheet().getUrl());
    MailApp.sendEmail(Session.getEffectiveUser().getEmail(), subject, lines.join("\n"));
  } catch (err) {
    console.error(err);
  }
}
```

4. 右上角 **部署 → 新增部署作業**：
   - 左邊齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網站伺服器要能送資料進來；別人沒有網址就送不進來，也看不到試算表內容）
   - 按 **部署**，第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。這是 Google 對自己寫的小程式的標準提醒。
   - 授權清單會有「**以你的名義傳送電子郵件**」：這是用來寄回饋通知給你自己，只會寄到你自己的信箱。
5. 複製畫面上的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`），貼給 Claude。

## Claude 接著做的

- 把網址存到 `data/feedback_sheet.json`（`data/` 不會上傳到 GitHub，網址不會公開）。
- 重啟網站，送一則測試回饋，確認試算表有新增一行，再把測試那一行刪掉。

## 注意

- **網址要保密**：知道網址的人可以往試算表裡寫東西（但看不到內容）。只存在 `data/feedback_sheet.json`，不要貼到公開的地方。
- 如果之後改了 Apps Script 的程式，要重新「部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署」，網址不會變。
- 設定好試算表後，回饋**只存在試算表**（使用者要求不在主機上留備份）。送不到時伺服器會重送 3 次；3 次都失敗，那一則會遺失。
- 每則回饋都會寄 email 到你的 Gmail（標題開頭是「【英文句子骨架分析】」）。免費 Gmail 帳號每天最多寄 100 封；網站本身也限制同一個人每小時最多 20 則。
- 以後網站搬到雲端主機時，把網址設成環境變數 `FEEDBACK_SHEET_URL` 就好。
