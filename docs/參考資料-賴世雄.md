# 參考資料：賴世雄《教你學英語語法》（上）（即《常春藤英文文法》簡體版）

> 閱讀筆記，只記錄觀念與頁碼，不轉載原文與例句（著作權）。網站一律使用繁體中文。
> 原書：使用者自己的電子檔。頁碼換算：書本頁碼 ＋ 15 ＝ PDF 頁碼。

## 全書架構

- 上冊專講句型結構：先建立句子主幹，再講如何把簡單句連成複雜句。
- 第一章 句子的構成（主詞的種類、動詞五分類、五大句型、祈使／感嘆／疑問句）
- 第二章 兩句的連接方法（標點、對等連接詞、連接副詞＝從屬連接詞、避免雙重連接）
- 第三章 關係詞（關係代名詞、關係副詞、複合關係代名詞、準關係代名詞 than／as）
- 第四章 非謂語動詞（不定詞、分詞）

## 重點

| 頁碼 | 內容 | 和我們規則的關係 |
|---|---|---|
| p.4 | 不定詞、動名詞當主詞太長時，用 it 當「虛主語」，真主語移到句尾 | ✅ 和「真主詞」標法一致 |
| p.6 | 名詞子句當主詞；名詞子句分 that、whether、疑問詞三種 | ✅ |
| p.17 | **動詞五分類**：完全不及物（c. vi.）、不完全不及物（i. vi.）、完全及物（c. vt.）、不完全及物（i. vt.）、授予動詞（d. v.） | 可以把這些台灣學生熟悉的名稱放進說明 |
| p.18 | **及物／不及物判斷法**：把動詞放進「我＿他」「他被我＿」，兩句都通順就是及物 | 很適合放進五大句型介紹頁和文法重點卡 |
| p.22 | 完全不及物動詞後面可以接副詞、介系詞片語、副詞子句當修飾 | ✅ |
| p.23 | 不完全不及物動詞（連綴動詞）＝ 後面要接主詞補語；**be ＋ 介系詞片語也算補語**（He is in danger） | ⚠️ 和我們目前的標法不同（見下方） |
| p.24 | be 後面接名詞 → 譯「是」；接形容詞 → 不必譯出；**接地點 → 譯「在」，地點是補語** | ⚠️ 同上 |
| p.44～45 | 不完全及物動詞：make 當「製造」是完全及物，當「使、叫」是不完全及物；使役動詞 make／have／bid ＋ O ＋ 原形動詞（原形動詞連同它的受詞一起當 OC） | ✅ 和我們的 OC 切法一致 |
| p.67～69 | **五大類句型的編號**（見下表） | ⚠️ 和教法 B 不同 |
