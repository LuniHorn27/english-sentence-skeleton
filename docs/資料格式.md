# 資料格式（0-5）

> 分析引擎（後端）和網頁畫面（前端）之間，用這裡定義的格式交換資料。
> 程式版的定義在 `backend/analyzer/schema.py`，會自動檢查格式是否正確；檢查指令：`python tests/validate_formats.py`。

## 1. 分析結果

後端分析一句話之後，回傳一份分析結果，結構像這樣：

```
分析結果
└── 句子（第 1 階段只有一句，第 2 階段可以多句）
    ├── 狀態：ok（完整）／partial（部分未分析）／failed（無法分析）
    ├── 句型：每個主要子句一個（對等句會有兩個以上）
    ├── 片段：依照句子順序排列
    │   └── 可以展開的子句內部片段（副詞子句、形容詞子句）
    └── 文法重點卡：要顯示哪幾張
```

### 1.1 句子

| 欄位 | 意思 | 例子 |
|---|---|---|
| `text` | 原句 | `I like tea, but she likes coffee.` |
| `status` | ok／partial／failed | `ok` |
| `message` | partial、failed 時給使用者看的提示 | 這句比較複雜，部分內容尚未分析 |
| `kind` | simple（一般句）／compound（對等句） | `compound` |
| `clauses` | 每個主要子句的句型 | 見 1.2 |
| `header` | 畫面標題，程式自動產生 | `句型二：S + Vt + O　＆　句型二：S + Vt + O` |
| `chunks` | 片段 | 見 1.3 |
| `cards` | 文法重點卡 | 見 1.4 |
| `translation` | 翻譯，後端留空，由網頁用瀏覽器翻譯填入 | |

### 1.2 句型

| 欄位 | 意思 | 例子 |
|---|---|---|
| `pattern` | 句型編號 1～5（教法 B） | `4` |
| `passive` | 是否為被動語態 | `false` |
| `formula` | 公式 | `S + Vt + IO + DO` |
| `label` | 句型＋公式，程式自動產生，**一定同時有編號和公式** | `句型四：S + Vt + IO + DO` |

### 1.3 片段

| 欄位 | 意思 | 例子 |
|---|---|---|
| `text` | 片段文字（**不含標點**，標點由畫面接在片段後面顯示） | `the funny boy` |
| `start`、`end` | 在句子中的字元位置 | `24`、`37` |
| `role` | 角色：S、Vt、Vi、V、aux、O、IO、DO、SC、OC、RS（真主詞）、conj、M（修飾語）、unknown（未分析） | `O` |
| `implicit` | 句子裡看不到的字，例如 (You) | `true` |
| `function` | 修飾語的功能（只有 M 才有） | `副詞・表地點` |
| `modifies` | 形容詞修飾的字（形容詞一定要有） | `boy` |
| `heads` | 核心字（粗體），可以有好幾個 | `boy` |
| `structure` | 結構，只出現在說明裡 | `介系詞片語` |
| `note` | 點片段時的說明 | 受詞，核心字是 boy。 |
| `clause` | 屬於第幾個主要子句（對等句用） | `1` |
| `inner` | 可以展開的子句內部片段 | who／likes／to cook |

**自動檢查的規則**
- 每個片段、核心字、修飾對象的字元位置，都必須和原句的文字一致（防止畫面標錯位置）。
- 修飾語一定要有功能；形容詞修飾語一定要有修飾對象。
- 對等句至少要有兩個子句。

### 1.4 文法重點卡的引用

| 欄位 | 意思 | 例子 |
|---|---|---|
| `id` | 卡片代號 | `quantifier_of` |
| `vars` | 填進卡片簡短說明的變數 | `{noun: kids}` → 「動詞單複數要看 of 後面的 **kids**」 |

## 2. 文法重點卡

每張卡是一個檔案，放在 `backend/cards/<代號>.yaml`，檔名要和代號一致。

| 欄位 | 意思 |
|---|---|
| `id` | 卡片代號（英文小寫、底線） |
| `title` | 卡片標題 |
| `brief` | 一句話的簡短說明，可以用 `{變數}` |
| `trigger` | 什麼情況要顯示（給人看的說明；實際判斷寫在程式裡） |
| `blocks` | 詳細說明的內容區塊，依序顯示 |
| `see_also` | 相關的卡片 |

### 內容區塊的種類

| 種類 | 畫面 | 用途 |
|---|---|---|
| `formula` | 藍色框＋公式圖示 | 公式 |
| `tip` | 黃色框＋燈泡圖示 | 小技巧 |
| `warn` | 紅色框＋警告圖示，可附 ✓／✗ 例句 | 常見錯誤 |
| `info` | 灰色框＋資訊圖示 | 補充 |
| `heading` | 小標題 | |
| `list` | 條列 | 多行說明一律用條列 |
| `examples` | 例句（英文＋淡色中文說明，可標 ✓／✗） | |

示範卡片：`present_progressive.yaml`（現在進行式）、`quantifier_of.yaml`（數量詞＋of，示範變數用法）。

**資安**：卡片內容由我們自己撰寫，只允許用 `<b>` 標粗體；使用者輸入的句子在畫面上一律當純文字顯示，不會當成網頁程式碼執行。
