## 各功能的規劃筆記

### F1　五大句型詳細介紹
- 一個獨立頁面：每種句型都有「規則、公式、判斷方法、例句、常見錯誤」，沿用文法重點卡的排版（公式、小技巧、常見錯誤區塊）。
- 句型標籤（例如「句型五：S + Vt + O + OC」）可以點擊，直接跳到該句型的介紹。
- **參考資料**：Azar《Understanding and Using English Grammar》、賴世雄的文法書、網路上的教學資源。
- **版權注意**：文法書的內容受著作權保護，只能參考觀念，**說明和例句必須自己寫**，不能直接照抄；可以在頁面上列出參考書目。
- 標籤、公式、編號要和〈標籤規則〉規格書一致（句型編號用教法 B）。

### F2　遊戲化學習
- 題型構想：
  - 判斷這句屬於句型幾
  - 點選句子裡的主詞、動詞、受詞、補語
  - 把片段拖到正確的標籤上（配對）
- **題目來源**：直接用題庫的句子（已經有人工審核過的標準答案），不用另外準備。
- 答錯時顯示對應的文法重點卡，錯題就是學習的機會。
- 進階：計分、連續答對、難度分級。

### F3　使用者回饋
- 每一句分析結果旁有「回報錯誤」按鈕，使用者可以指出哪個片段標錯，以及他認為的正確答案。
- 另有「提供建議」表單。
- **流程**：回報 → 你審核 → 確認是錯的，就加進題庫當新的考題 → 修正規則 → 跑測試。這樣每個錯誤都會讓工具變得更好。
- **資安／隱私**：限制次數防洗版；不收集個人資料；回報內容不直接公開顯示。
- 還沒上線前，可以先用免費的 Google 表單收集，不用自己寫資料庫。

### F4　朗讀按鈕
- 使用瀏覽器內建的語音朗讀（Web Speech API），**免費**，不用另外架伺服器。
- 功能：朗讀整句、點片語只唸那一段、調整語速（慢速適合跟讀）。
- 限制：不同瀏覽器和手機的聲音不一樣，部分裝置的聲音比較機械。

### F5　起心動念
- 「關於這個工具」頁面：說明製作的初衷，是希望幫助台灣的學生和英文學習者更便利地學英文。
- 同一頁可以放：使用方式、分析結果僅供參考的提醒、回饋管道、隱私說明。

### F6　分享按鈕
- 手機上使用系統內建的分享功能（Web Share API），可以直接選 LINE、Facebook、Instagram 等 App。
- 電腦上提供常用社群的分享連結和「複製連結」。
- **進階**：分享「某一句的分析結果」，朋友點開連結就看到同一句的拆解。
- 要等網站上線（第 3 階段）才有網址可以分享。

### F7　英文學習資源庫
- 整理免費、可信的學習資源連結，依類別分類（文法、單字、聽力、閱讀、考試）。
- **注意**：只放連結和自己寫的簡介，不轉載對方的內容；定期檢查連結是否失效。
