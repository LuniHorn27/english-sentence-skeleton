五大句型

英文句子不管多長，骨架都逃不出這五種。先認識骨架，再看分析結果就會清楚很多。

怎麼找出句子的骨架？

  1. 找動詞：找出句子最核心的動作或狀態（會跟著主詞、時態變化的那個字）。
  2. 問「誰」：是誰在做這個動作？答案就是主詞 S。
  3. 看動詞後面需要什麼：不需要東西、需要受詞、需要補語，還是需要兩個成分？這決定了是哪一種句型。
  4. 其他都是修飾語：時間、地點、方式、形容名詞的片語……拿掉之後，骨架仍然完整。
ℹ
關於句型編號不同教科書的句型編號不太一樣。本網站採用賴世雄《常春藤英文文法》的編號：句型二是 S + V + SC、句型三是 S + Vt + O、句型四是 S + Vt + O + OC、句型五是 S + Vt + IO + DO。編號一定和公式一起出現，看公式就不會搞混。

標籤對照

最容易搞混：句型四（S + Vt + O + OC）vs 句型五（S + Vt + IO + DO）

兩種句型的動詞後面都有兩個成分，差別在於：第二個成分和第一個成分是不是「同一個東西」。

💡
小技巧等號測試：him = happy？說得通，所以是句型四（O + OC）。him = a cake？不對，所以是句型五（IO + DO）。
