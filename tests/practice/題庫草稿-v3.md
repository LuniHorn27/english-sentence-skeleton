# 標準答案題庫（草稿 v3，待審核）

用途：之後每次改程式，都拿這份題庫自動檢查準確率。
請你逐句檢查「拆解」是否符合你想教的方式。有意見直接寫在該句的「審核意見」欄。

## 已確定的規則（v3）

| 項目 | 決定 |
|---|---|
| 句型呈現 | 句型編號（賴世雄版）＋ 完整公式，公式和標籤一致：句型一：S + Vi／句型二：S + V + SC／句型三：S + Vt + O／句型四：S + Vt + O + OC／句型五：S + Vt + IO + DO |
| 動詞標籤 | 只用 `Vt`、`Vi`、`V`。連綴動詞（be、look、become…）標 `V`，「連綴動詞」寫在說明裡 |
| 助動詞 | 標 `aux.`，畫面用虛線底線，不算進公式。進行式、完成式也拆開：`[aux. is] [Vi sleeping]` |
| 祈使句 | 省略的主詞以 `(You)` 呈現，標 `S`，實線底線（算進公式）；句子下方附「文法重點」 |
| There is／are | 歸為句型一 S + Vi，be 動詞標 `Vi`；There 標「引導詞」；句子下方附「文法重點」 |
| 修飾語 | 畫面只顯示功能（例如「形容詞・修飾 tree」「副詞・表時間」），結構寫在說明裡 |
| 被動語態 | 標題寫「原本的句型（被動語態）」；be 標 `aux.`，p.p. 標 `Vt`；by＋執行者標「副詞・表執行者」；句型五、五被動後剩下的部分**照原本的角色標**（DO、OC）；附「被動語態」文法重點卡 |
| 核心字 | 片語中其他字都在形容它的那個字。「數量詞 ＋ of ＋ 名詞」（Most of、each of…）不標核心字，改附「文法重點」；「單位詞 ＋ of ＋ 名詞」（a glass of…）核心字是 of 後面的名詞 |
| 文法重點卡 | 句子用到的時態、特殊句型、常見用法，在句子下方顯示簡短說明，可展開詳細內容（公式、小技巧、常見錯誤） |

## 標記方式

- `[S The cat]`：方括號是一個片段，前面是角色。
- 修飾語：`[M 功能 文字]`，例如 `[M 形容詞・修飾tree behind our house]`、`[M 副詞・表時間 in the fall]`
- `核心:` 表示片段裡最重要的那個字。
- ⚠️ 表示還需要你決定。
